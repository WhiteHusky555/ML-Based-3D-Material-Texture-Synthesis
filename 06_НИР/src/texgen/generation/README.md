# Генерация albedo

`POST /generate` принимает PNG-карту высот в base64, описание материала, seed и флаг upscale. Вход для ControlNet — RGB-карта высот 512×512. При upscale стенд увеличивает albedo до 1024×1024 фильтром Lanczos. Нейросетевой апскейл Real-ESRGAN запланирован отдельно.

## Публикация версии

Разместите локальный комплект Diffusers в `06_НИР/models/<версия>/`: SD 1.5 в `base/`, совместимый ControlNet для глубины в `controlnet/`, опциональные веса в `adapter/pytorch_lora_weights.safetensors`. Проверьте происхождение комплектов. Каталог доступен на запись только локальному администратору, в контейнер монтируется для чтения. Опубликованный комплект сохраняйте неизменным для отката.

Из каталога НИР:

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
python -m texgen.generation.registry 1 v1 --root models
Invoke-RestMethod http://localhost:8012/ready
```

Один процесс обслуживает одну GPU. Между заданиями он сверяет SHA-256 комплекта и выполняет пробный инференс. Повторная публикация того же номера и содержимого безопасна. Для замены или отката укажите больший номер публикации и нужную версию каталога. При ошибке загрузки воркер пытается восстановить прежний комплект. После рестарта проверяет публикации от новой к старой. В ответе готовности указаны активная версия и ошибка последней попытки. Во время загрузки или обработки другого задания генератор отвечает `503 model_busy`.
