# Нейросетевая генерация и апскейл

Планируемый GPU-сервис получает карту шума, текстовое описание материала, конфигурацию модели и отдельный seed диффузии. Он генерирует albedo и увеличивает разрешение карты перед передачей в PBR. Обучение весов выполняется отдельно в Kaggle.

Сейчас каталог фиксирует границу сервиса. Реализация инференса и апскейла запланирована.
