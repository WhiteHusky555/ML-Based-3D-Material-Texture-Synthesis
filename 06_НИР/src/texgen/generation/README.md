# Генерация albedo и апскейл

Проектный контракт GPU-модуля для инференса. Обучение весов выполняется отдельно в Kaggle.

| Вход | Назначение |
|---|---|
| Карта шума | Пространственное условие генерации |
| Текстовое описание | Свойства материала |
| Конфигурация модели | Параметры инференса |
| Seed диффузии | Начальное состояние генератора случайных чисел для диффузии |

Для сравнения нескольких карт шума фиксируйте описание, конфигурацию и seed диффузии. Albedo после апскейла передаётся в [модуль PBR](../pbr/README.md).
