# Расчёт PBR-карт

Проектный контракт модуля обработки материала.

| Вход | Источник |
|---|---|
| Albedo после апскейла | [Генерация текстур](../generation/README.md) |
| Периодическая карта высот | [Генератор шума](../noise/README.md) |
| Пресет материала | Параметры расчёта PBR |

Выходные карты — `height`, `normal`, `roughness` и `AO`. При сравнении нормалей с эталоном приведите обе карты к одному направлению оси Y. Методика проверки описана в [плане НИР](../../../docs/PLAN.md).
