# Генерация шума

Вычислительное ядро на CPU с Numba принимает вид шума (`perlin`, `voronoi` или `combined`), размер, число ячеек и seed. Функция `generate` возвращает двумерную периодическую карту высот со значениями от 0 до 1.

Из каталога НИР с `src` в PYTHONPATH выполните `python -m texgen.noise --output examples/noise`. Команда сохраняет карты PNG и повтор каждой карты 2×2 для проверки стыков. Будущий обработчик FastAPI будет вызывать то же ядро.
