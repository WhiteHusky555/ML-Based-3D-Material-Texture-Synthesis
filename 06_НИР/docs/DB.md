# Данные и хранение

Для эксперимента достаточно файлов и двух манифестов. Манифест датасета содержит material_id, источник, лицензию, категорию, split, пути карт и описание. Исходный материал принадлежит одному разбиению вместе со всеми его кропами. Перед обучением проверить уникальность ID и отсутствие пересечений.

Манифест запуска содержит run_id, версию схемы, конфигурацию, версии моделей, оба seed, ссылки на входные и выходные файлы, метрики и статус. Сохранять результаты в каталоге запуска, публиковать итоговый статус после записи всех карт. При изменении формата повышать версию схемы. Данные и веса доступны исследователю в приватном пространстве Kaggle.

## Сервисный стенд и обновление модели (проект)

Для локального стенда хранить неизменяемые комплекты весов по версиям, желаемую публикацию и последнюю успешно активированную публикацию. Указатели обновлять атомарной заменой файла. На старте сверять желаемую ревизию с подтверждённой и проверять контрольные суммы перед загрузкой. Манифест результата содержит фактическую версию.
