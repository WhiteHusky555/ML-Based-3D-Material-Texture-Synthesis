# Технические требования

Первый стенд — Kaggle Notebook, Python, SD 1.5, вход 512×512, fp16 и batch size 1. Обучается LoRA U-Net. Базовые веса, ControlNet и Real-ESRGAN фиксируются по версии. Скорость и пик выделенной GPU-памяти измеряются на пробном запуске.

Процедурный модуль принимает тип шума, масштаб и seed и возвращает периодическую карту высот. GPU-модуль получает карту, текст, конфигурацию и отдельный seed диффузии, генерирует albedo и выполняет апскейл. PBR-модуль получает albedo, карту высот и пресет и рассчитывает height, normal, roughness и AO. В первом опыте модули вызываются последовательно внутри ноутбука. Те же входы и выходы служат контрактами будущих воркеров.

Проверять размер, диапазон, формат карт и параметры на входе каждого модуля. Записывать версии весов, библиотек, устройство и настройки. Чекпойнты и манифест сохранять для возобновления обучения. Секреты передавать через окружение.

## Сервисный стенд и обновление модели (проект)

Предлагаемый стенд НИР запускает три отдельных процесса FastAPI и клиент конвейера. Клиент передаёт периодическую карту высот в генератор вместе с описанием и seed, затем передаёт albedo и высоты в PBR. Каждый сервис имеет собственный requirements.txt. Процесс инференса запускается без весов и возвращает 503 model_unavailable до подключения модели. Для стенда используется один процесс на GPU.

Версии моделей адресуются неизменяемым идентификатором, манифестом и SHA-256 локальных файлов safetensors. Путь разрешается только внутри каталога моделей. На одной GPU обновление прекращает приём новых заданий, дожидается текущего, загружает кандидата и выполняет пробный инференс. При неудаче восстанавливается предыдущая версия с диска; при ошибке восстановления readiness остаётся отрицательной. Монотонный номер публикации отделён от версии весов: откат публикует новую ревизию с прежними весами. Повтор той же публикации идемпотентен, устаревшая игнорируется. Каждое задание фиксирует версию, обработавшую его.

В дипломной системе версии принадлежат admin-service, команду администратора обслуживает staff-ui, доставка GPU-воркерам идёт через model_version.published. В НИР предлагается локальная административная CLI с доступом через права ОС к каталогу публикаций. Изменение версии по общедоступному HTTP исключено.
