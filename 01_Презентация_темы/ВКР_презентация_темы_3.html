Актуальность

Материалы для 3D-графики создаются долго

Каждой поверхности в игре или 3D-сцене нужен набор карт: цвет, нормали, высота, шероховатость. Сейчас их получают тремя способами, и у каждого есть ограничение.

Процедурные редакторы

Substance 3D Designer и аналоги

Полный контроль формы, бесшовность, все PBR-карты
Нужен опытный технический художник, сложный граф узлов, один материал может занимать часы

Библиотеки готовых материалов

ambientCG, Poly Haven

Быстро, бесплатно, качественные сканы
Ограниченный набор, одни и те же материалы у всех проектов, нельзя получить то, чего нет в библиотеке

Генеративные нейросети общего назначения

text-to-image модели

Любой материал по текстовому описанию
Нет контроля формы, перспектива и тени на изображении, видимые швы при укладке, нет PBR-карт
Идея работы

Совместить подходы: процедурный шум задаёт управляемую форму, нейросеть рисует реалистичную фактуру, программа доводит результат до бесшовного набора PBR-карт.

Цель и задачи

Что должно получиться

Разработать программное обеспечение, которое по параметрам процедурного шума и текстовому описанию материала генерирует бесшовный набор PBR-карт, готовый для использования в Blender, Unity и Unreal Engine.

  1. Проанализировать подходы и программные средства создания материалов
  2. Сформулировать требования и спроектировать сервисную архитектуру
  3. Реализовать сервис процедурной генерации шума (Перлин, Вороной)
  4. Интегрировать предобученные модели: диффузионную с управлением по карте и модель сверхразрешения
  5. Обеспечить бесшовность результата на всех этапах обработки
  6. Реализовать расчёт PBR-карт: высот, нормалей, шероховатости, затенения
  7. Разработать веб-интерфейс с превью и 3D-просмотром материала
  8. Провести экспериментальную оценку качества и производительности

Использование нейросетей

Где работают нейросети

Модель 1. Генерация текстуры

Stable Diffusion 1.5 + ControlNet + LoRA · предобученные веса
Текст → кодировщик CLIPчто рисовать: «cobblestone pavement, top-down, flat lighting»
Карта шума → ControlNetгде что расположено: границы камней, углубления
→ → → →
случайный шум20–30 шагов очистки, схематекстура
LoRAДообучается в курсовой на текстурах ambientCG: модель рисует плоские текстуры без перспективы и теней
Циклический paddingСвой патч свёрточных слоёв: модель рисует так, будто края склеены, результат бесшовный

Модель 2. Сверхразрешение

Real-ESRGAN · предобученные веса
→

512² → 2048² с дорисовкой мелких деталей. Своё: циклическое дополнение краёв для бесшовности и обработка по тайлам под объём видеопамяти.

Без нейросетей

Свой код: шум, карта высот, нормали, шероховатость, AO, бесшовный апскейл, сервисы и интерфейс.

С нуля модели не обучаются. Рельеф берётся в основном из шума, поэтому геометрия управляемая и предсказуемая.

Сервисы и потоки данных

свой кодобёртка над модельюготовый сервис
  • Брокер сообщений RabbitMQНадёжная доставка задач с подтверждением, отдельные очереди под GPU и CPU, события статусов для API

  • ЗапускВесь стек поднимается через Docker Compose

Эксперименты ВКР

  • Время каждого этапа и полное время получения материала
  • Пропускная способность на одной видеокарте, материалов в час
  • Задержка превью шума при загруженной GPU
  • Эффект кэша при повторных запросах
  • Пиковая видеопамять генерации и апскейла
  • Проверка материалов в Blender и Unity
  • Сравнение NumPy, Numba и OpenCL на 512²–4096²

Ожидаемые результаты

  • Работающий прототип, запускаемый одной командой
  • Библиотека сгенерированных бесшовных материалов с полным набором карт
  • Таблицы и графики производительности
  • Исходный код и документация по развёртыванию

Особенность решения

Управление формой через процедурный шум и генерация фактуры диффузионной моделью объединены в одном конвейере, с бесшовностью на каждом этапе и выдачей полного набора PBR-карт.

Практическая значимость

Быстрое получение уникальных материалов для небольших команд, учебных проектов и прототипирования уровней. Работает локально, без платных сервисов.
