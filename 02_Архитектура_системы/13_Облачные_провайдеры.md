# Облачные провайдеры

Решение (14.10.2026): система разворачивается **в облаке**, предварительно — **AWS**. Yandex Cloud **исключён**.
Цены собраны 14.10.2026, это ориентиры: перед расчётами для ВКР перепроверить в AWS Pricing Calculator.

## 1. AWS — основной вариант

### Какие сервисы AWS под какие части системы
| Часть системы | Сервис AWS |
|---|---|
| Kubernetes | **Amazon EKS** (управляемый кластер) |
| GPU-воркеры | EC2 **g6.xlarge**: 1× NVIDIA **L4 24 ГБ**, 4 vCPU, 16 ГБ RAM |
| CPU-сервисы | узлы общего назначения EC2 (EKS managed node group / Karpenter) |
| PostgreSQL | **Amazon RDS for PostgreSQL** |
| Объектное хранилище | **Amazon S3** (тот же S3 API, что у MinIO — код не меняется) |
| RabbitMQ | **Amazon MQ for RabbitMQ** или RabbitMQ в кластере (Cluster Operator) |
| Балансировщик | Network Load Balancer (перед нашим nginx) |
| Реестр образов | Amazon ECR |
| Секреты | AWS Secrets Manager |
| Сертификаты | AWS Certificate Manager или cert-manager |
| CDN (по желанию) | Amazon CloudFront — статика и скачивание архивов |
| Логи | Amazon CloudWatch |

Источники: DevZero, Vantage (instances.vantage.sh), страницы AWS G4/G6.

**Почему g6.xlarge (L4 24 ГБ):**
- 24 ГБ видеопамяти снимают главное ограничение из презентации (8 ГБ): помещаются SD + ControlNet + IP-Adapter + Real-ESRGAN одновременно и остаётся место под LLM подсказок; в перспективе — модель класса SDXL.
- G6 по данным AWS даёт до 2× производительности графики по сравнению с G4dn.
- L4 поддерживает fp16/bf16 — подходит для диффузии.

### Управляемые сервисы (ориентиры)
| Сервис | Конфигурация | Цена |
|---|---|---|
| RDS PostgreSQL | db.t4g.micro, Single-AZ | ~$0,016/ч (~$12/мес) — для старта |
| Amazon MQ (RabbitMQ) | mq.t3.micro, одиночный брокер | ~$0,027/ч (~$20/мес); бесплатных часов брокера нет |
| Amazon MQ (RabbitMQ) | mq.m5.large | $0,288/ч (~$214/мес); кластер — ×3 |
| EKS | плата за кластер | около $0,10/ч (~$73/мес) *(по памяти, проверить)* |

Amazon MQ дороже равного EC2 в 2,5–3 раза (CloudFix). Для старта дешевле держать RabbitMQ в кластере через RabbitMQ Cluster Operator.

### Сколько стоит GPU и как экономить
- Один g6.xlarge on-demand 24/7: 0,805 × 730 ч ≈ **$588/мес**.
- Способы снизить:
  1. **Масштабирование до нуля** ночью и при пустой очереди (KEDA + Karpenter); цена — холодный старт (поднять узел и загрузить модели, порядка минут).
  2. **Spot-узлы для бесплатного тарифа:** прерывание не страшно — задача без подтверждения вернётся в очередь (`acks_late`).
  3. **Минимум один on-demand узел для премиума** в рабочие часы — без холодного старта.
  4. **Резерв на год** при стабильной нагрузке (−25–35 %).
- Затраты на GPU окупает премиум-тариф. Отсюда лимиты бесплатного тарифа (10 генераций в сутки, 1024²).

### Оговорки
- AWS не работает с клиентами из России (новые регистрации закрыты с 2022 г.). Автор живёт в Европе, для него это не ограничение. Но если сервис будет для пользователей из РФ, по **152-ФЗ** персональные данные граждан РФ нужно хранить на серверах в России. Это вопрос к будущему запуску, на ВКР не влияет.
- Регион для пользователей в Европе — eu-north-1 (Стокгольм) или eu-central-1 (Франкфурт).

## 2. GPU-облака — дешевле для воркеров
| Провайдер | Пример цены | Комментарий |
|---|---|---|
| **RunPod** | L4: $0,39–0,59/ч (выросла за август 2026 г.); RTX 4090: $0,34–0,69/ч | поминутная оплата, есть serverless; по обзорам на 40–60 % дешевле AWS, но надёжность ниже |
| **Lambda** | A10 24 ГБ: $1,29/ч | ориентир на кластеры и обучение |
| **Vast.ai** | маркетплейс, цены ниже всех | нестабильная доступность |
| Медиана по рынку | T4: $0,64/ч (10 провайдеров, 01.10.2026) | getdeploying.com |

**Гибридная схема** (архитектура её уже допускает): ядро системы в AWS (EKS, RDS, S3, RabbitMQ), а GPU-воркеры в RunPod. Они подключаются к RabbitMQ и S3 по TLS. Код воркера тот же — Celery всё равно, где он запущен. Это вариант снизить главную статью расходов.

## 4. Итог
- **Основной вариант:** AWS EKS + g6.xlarge (L4 24 ГБ) + RDS + S3 + RabbitMQ в кластере.
- **Экономия:** spot и масштабирование до нуля для бесплатного тарифа; при необходимости — гибрид с RunPod для GPU.
- **Локализация в РФ:** Selectel — архитектура переносится без изменения кода, смета и план в [18](18_Развёртывание_в_Selectel.md).
