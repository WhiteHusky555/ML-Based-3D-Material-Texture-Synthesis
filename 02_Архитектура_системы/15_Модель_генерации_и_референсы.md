# Модель генерации, референсы и загрузка моделей

Вопрос (14.10.2026): какую основную модель генерации используем, будет ли поддержка загрузки референсов и моделей?
Сведения о моделях собраны 14.10.2026 (обзоры Thunder Compute, BentoML, Pinggy, Pixazo, Medium — см. внизу). Лицензии перепроверить по карточкам моделей перед запуском.

## 1. Что важно для выбора
1. **Лицензия под платный сервис** (у нас премиум-тариф).
2. **Экосистема:** ControlNet (форма из шума), LoRA (дообучение из курсовой), IP-Adapter (референс-картинка).
3. **Бесшовность:** наш способ — циклический padding в свёртках. Он работает в моделях на **UNet** (SD 1.5, SDXL). В моделях на трансформерах (DiT: FLUX, Qwen-Image, Z-Image, SD 3.5) свёрток в основной сети почти нет, нужны другие приёмы (сдвиг латента на каждом шаге и т. п.), их пришлось бы исследовать заново.
4. **Видеопамять:** облачный GPU — L4 24 ГБ.

## 3. Решение
**Ограничение (14.10.2026): много моделей для ВКР обучить не получится.** Поэтому:

**Одна базовая модель для всех тарифов — SD 1.5 + ControlNet + LoRA.** Дообучается **только LoRA, один раз, в курсовой**. Всё остальное — готовые предобученные веса без обучения:
| Компонент | Обучение |
|---|---|
| SD 1.5 | нет, готовые веса |
| **LoRA** | **да — единственная дообучаемая модель, в курсовой** |
| ControlNet | нет, готовые веса |
| IP-Adapter (референсы) | нет, готовые веса |
| Real-ESRGAN | нет, готовые веса |
| LLM для подсказок | нет: Ollama / OpenRouter |

**Чем тогда премиум «лучше» без второй модели:**
| Возможность | Бесплатный | Премиум |
|---|---|---|
| Итоговое разрешение | 1024² | 2048², 4096² (апскейл) |
| Шагов диффузии | 20 | 30–40, планировщик получше |
| Вариантов за запуск | 1 | до 4 |
| Референс-картинка (IP-Adapter) | нет | да |
| Подсказки к промпту | нет | да; можно более сильную LLM (облачную через OpenRouter) — тоже без обучения |
| Форматы, хранение, приоритет | базовые | расширенные |

**В перспективы развития (после ВКР):** SDXL + своя LoRA для премиума; модели на трансформерах с Apache 2.0 (Z-Image Turbo, FLUX.2 [klein]) — когда появятся зрелые ControlNet и LoRA и найдётся способ бесшовности для DiT.

**Не используем:** FLUX [dev] (некоммерческая лицензия), Qwen-Image 2.1 (только исследования).

## 4. Загрузка референсов — да
| Режим | Как работает | Тариф |
|---|---|---|
| **Референс фактуры** (картинка-образец) | **IP-Adapter**: картинка задаёт внешний вид (цвета, материал), **шум — форму** через ControlNet, текст — смысл. Diffusers поддерживает IP-Adapter вместе с ControlNet для SD 1.5 и SDXL | премиум (или пробно бесплатно) |
| Сила референса | ползунок `ip_adapter_scale` (как «image strength» у Polycam) | — |
| Фото → бесшовный материал (будущее) | загруженное фото делается бесшовным (дорисовка краёв) и прогоняется через PBR-сервис | — |

Что меняется в системе:
- API: `POST /api/references` — загрузка картинки (JPEG/PNG/WebP, до 10 МБ) → S3, бакет `references`; в задаче — ссылка на референс.
- Проверки: тип и размер файла, пересжатие картинки на сервере (снимает метаданные и вредоносное содержимое), лимит загрузок по тарифу.
- Срок хранения референса = сроку хранения материала.
- В хэш кэша добавляется хэш референса.

## 5. Загрузка 3D-моделей
| Вариант | Что это | Решение |
|---|---|---|
| **Своя модель для просмотра материала** | пользователь загружает GLB / OBJ / FBX и видит готовый материал на своей модели в 3D-просмотре (UV или трипланарная проекция для моделей без развёртки) | ✔ **да** — простая функция веб-клиента и S3, хорошо продаёт премиум |
| Текстурирование прямо по модели (как Meshy) | генерация под UV-развёртку конкретной модели: многоракурсная диффузия, проекция, запекание | ✘ **не в ВКР** — другая задача и другой класс систем (см. `03_Аналоги`); в «перспективы развития» |

## 6. Загрузка своих моделей ИИ (LoRA)
- Можно как премиум-функцию: пользователь загружает свою LoRA в формате **только safetensors** (pickle-файлы `.ckpt`/`.pt` нельзя — в них может быть исполняемый код), до ~200 МБ, проверка совместимости с базовой моделью.
- GPU-воркер подгружает LoRA к задаче и держит несколько последних в кэше видеопамяти.
- Риски: лицензии чужих LoRA, злоупотребления — пользовательское соглашение.
- Обучение своей LoRA внутри сервиса (как у Scenario) — перспектива развития, не ВКР.
