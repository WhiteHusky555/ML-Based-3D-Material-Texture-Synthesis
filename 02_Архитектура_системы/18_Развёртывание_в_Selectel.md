# Развёртывание в Selectel

Исследование 27.10.2026. Дополняет [13](13_Облачные_провайдеры.md), где Selectel был упомянут одной строкой как вариант для локализации данных в РФ.
Цены — с сайта selectel.ru/prices на 27.10.2026, **с НДС 22 %**, регион Санкт-Петербург (пул ru-9), месяц = 730 ч. Цены меняются: перед расчётами в ВКР перепроверить в калькуляторе Selectel.

## 1. Зачем рассматривать Selectel
- **152-ФЗ:** персональные данные пользователей из РФ должны храниться в России; AWS для этого не подходит, а инфраструктура Selectel имеет аттестацию под 152-ФЗ (у облачных БД заявлены также ГОСТ Р 57580, ISO, PCI DSS).
- **Оплата в рублях** и цены, не зависящие от курса.
- **Раздел о ситуации в РФ** в ВКР: Selectel — один из крупнейших российских облачных провайдеров с Managed Kubernetes и GPU, то есть реальная площадка для такой системы.
- **Архитектура переносится без изменения кода:** Kubernetes, S3-совместимое хранилище, PostgreSQL, Karpenter для автомасштабирования — всё это у Selectel есть.

## 2. Соответствие сервисов AWS и Selectel
| Часть системы | AWS ([13](13_Облачные_провайдеры.md)) | Selectel |
|---|---|---|
| Kubernetes | Amazon EKS | **Managed Kubernetes**: базовый кластер (1 мастер-нода, без SLA) или отказоустойчивый (3 мастер-ноды, SLA 99,98 %) |
| GPU-воркеры | EC2 g6.xlarge: L4 24 ГБ | облачный сервер с **NVIDIA L4 24 ГБ** — та же видеокарта; группа нод с GPU, драйверы предустановлены |
| Автомасштабирование узлов | Karpenter | Cluster Autoscaler (встроен) или **Karpenter с провайдером Selectel** (ставится из готового Helm-чарта) |
| Масштабирование по очередям | KEDA | KEDA — не зависит от облака, без изменений |
| Spot-узлы | EC2 Spot | **прерываемые группы нод** (регионы Санкт-Петербург, Москва, Новосибирск), в Karpenter — `capacity-type: spot` |
| PostgreSQL | Amazon RDS | **облачные базы данных PostgreSQL** |
| Объектное хранилище | Amazon S3 | **S3 Selectel** (S3-совместимый API: код и presigned-ссылки те же, меняется адрес и ключи) |
| RabbitMQ | Amazon MQ или в кластере | **только в кластере** (RabbitMQ Cluster Operator): управляемого RabbitMQ у Selectel не нашёл, есть Managed Kafka |
| Redis (для BFF, [17](17_Предложение_внедрения_BFF.md)) | ElastiCache | облачные базы данных Redis |
| Балансировщик перед nginx | NLB | балансировщик нагрузки Selectel (создаётся для Service типа LoadBalancer) |
| Реестр образов | Amazon ECR | Container Registry |
| CDN (по желанию) | CloudFront | CDN Selectel |
| Мониторинг | CloudWatch | Prometheus + Grafana в кластере (как и планировалось) |

## 3. GPU
### Видеокарты облачных серверов (цена карты; vCPU и RAM оплачиваются отдельно)
| Карта | Память | ₽/ч | ₽/ч, прерываемая | Комментарий |
|---|---|---|---|---|
| **L4** | 24 ГБ | **49,74** | **24,87** | та же карта, что в AWS g6.xlarge: расчёты видеопамяти из [13](13_Облачные_провайдеры.md) и [15](15_Модель_генерации_и_референсы.md) не меняются |
| Tesla T4 | 16 ГБ | 43,08 | 12,93 | дешевле всех прерываемых, но медленнее и меньше памяти |
| A4000 | 16 ГБ | 38,77 | 19,38 | — |
| A5000 | 24 ГБ | 60,27 | 30,14 | — |
| A30 | 24 ГБ | 57,64 | 31,00 | — |
| RTX 4090 | 24 ГБ | 75,40 | 37,70 | быстрее L4 на диффузии, но дороже |
| A100 | 40 ГБ | 206,38 | 88,45 | избыточна для SD 1.5 |

vCPU для сервера с L4 — 1,0071 ₽/ч (прерываемый 0,5036), RAM — 0,3662 ₽/ГБ в час (прерываемая 0,1831), сетевой SSD — 0,0144 ₽/ГБ в час.

### Выбор: L4 24 ГБ
- Та же видеокарта, что выбрана для AWS, поэтому выбор модели, вывод «24 ГБ снимают ограничение 8 ГБ» и пакетная загрузка моделей на один GPU остаются в силе.
- Из карт на 24 ГБ L4 самая дешёвая в час — и в обычном, и в прерываемом варианте.
- **GPU-нода** 6 vCPU, 24 ГБ RAM, 100 ГБ SSD, 1× L4: **66,01 ₽/ч ≈ 48 190 ₽/мес**; прерываемая — **33,73 ₽/ч ≈ 24 622 ₽/мес**.
- Сравнение с AWS: g6.xlarge on-demand стоит $0,805/ч (4 vCPU, 16 ГБ). Нода Selectel выходит дешевле при курсе выше ~82 ₽/$ (66,01 / 0,805), при этом у неё больше vCPU и памяти. Прерываемая нода Selectel стоит фиксированно, в отличие от spot-цены AWS, которая меняется по регионам и времени.

## 4. Managed Kubernetes
| Параметр | Значение |
|---|---|
| Базовый кластер (1 мастер-нода, без SLA) | 8,16 ₽/ч, **5 954,57 ₽/мес** — для демонстрации и проверки |
| Отказоустойчивый кластер (3 мастер-ноды, SLA 99,98 %) | 23,40 ₽/ч, **17 085,59 ₽/мес** — для работы |
| Рабочие ноды | оплачиваются как облачные серверы (vCPU, RAM, диск, GPU) |
| Ноды на выделенных серверах, в том числе с GPU | поддерживаются (новость Selectel на Хабре); дешевле облачных при постоянной нагрузке, оплата периодом от суток, скидка до 15 % за год |
| Лимиты | до 15 нод в группе, до 32 vCPU и 256 ГБ RAM на облачную ноду, до 100 подов на ноду |
| Масштабирование до нуля | поддерживается, если в других группах нод остаётся не меньше двух нод |
| GPU в группах нод | готовые конфигурации с GPU и предустановленными драйверами; без предустановленных драйверов автомасштабирование группы недоступно |

**Как это ложится на нашу схему масштабирования** ([12](12_Kubernetes_и_асинхронность.md)):
- группа `cpu`: 3 ноды по 4 vCPU и 8 ГБ, без автомасштабирования до нуля — системные компоненты, nginx, сервисы, RabbitMQ, мониторинг;
- группа `gpu-premium`: L4, обычные ноды, 0–N (минимум 1 в рабочие часы — без холодного старта для премиума);
- группа `gpu-free`: L4, **прерываемые** ноды, 0–N, масштабирование до нуля ночью; прерывание не страшно — задача без подтверждения вернётся в очередь (`acks_late`);
- KEDA добавляет поды GPU-воркеров по длине очереди `gpu`, Cluster Autoscaler или Karpenter добавляет под них ноды. Схема та же, что в AWS; меняются только метки групп нод в values Helm-чарта.

## 7. План развёртывания
| Шаг | Что делаю | Как проверяю |
|---|---|---|
| 1 | Аккаунт и проект Selectel; квоты на vCPU, RAM и GPU (L4) в выбранном пуле — при нехватке заявка в поддержку | в панели видны квоты под максимальный размер групп нод |
| 2 | Terraform (провайдер Selectel): приватная сеть, кластер Managed Kubernetes, группы нод `cpu`, `gpu-premium`, `gpu-free` (прерываемая), PostgreSQL, Redis, бакет S3, Container Registry | `terraform plan` без ошибок; кластер в статусе `ACTIVE`, `kubectl get nodes` |
| 3 | CI: сборка образов и загрузка в Container Registry; `imagePullSecret` в кластере | поды тянут образы из реестра |
| 4 | Helm-чарт texgen с файлом `values-selectel.yaml`: адрес и ключи S3 (через Secret), строка подключения PostgreSQL, метки и taints GPU-групп, Service nginx типа LoadBalancer, storageClass для томов RabbitMQ | все поды `Running`; генерация материала проходит от начала до конца |
| 5 | KEDA по длине очередей, автомасштабирование групп GPU (Cluster Autoscaler или Karpenter) | при пустой очереди `gpu-free` уходит в ноль; при задачах нода поднимается, задача выполняется |
| 6 | DNS, TLS (cert-manager), при необходимости CDN | сайт открывается по HTTPS, сертификат валиден |
| 7 | Мониторинг: Prometheus + Grafana (kube-prometheus-stack) | графики очередей и загрузки GPU в Grafana |

Код сервисов не меняется: всё, что отличает Selectel от AWS, — значения в `values-selectel.yaml` и описание инфраструктуры в Terraform.

## 8. Ограничения и риски
- **Оплата для нерезидентов РФ:** только картой МИР или российской Visa/MasterCard, через ЮMoney или банковским переводом; иностранные карты не принимаются. Для реального развёртывания мне понадобится российский способ оплаты (или юридическое лицо в РФ), для ВКР достаточно расчёта и плана.
- **Квоты и наличие:** конфигурации с GPU доступны не во всех пулах, квоты проекта на GPU нужно согласовать заранее.
- **Базовый кластер без SLA:** при отказе единственной мастер-ноды Control Plane не работает — уже запущенные поды обычно продолжают работать, но автомасштабирование, перезапуск подов и развёртывание недоступны. Для работы — отказоустойчивый кластер.
- **Пользователи в Европе:** дата-центры в России, задержка выше, чем у eu-north-1. Для асинхронной генерации это некритично; скачивание архивов можно ускорить через CDN.
- **152-ФЗ:** аттестованная инфраструктура не снимает обязанностей оператора персональных данных (политика обработки, уведомление Роскомнадзора) — их выполняет владелец сервиса.
- **Цены** публикуются с НДС и меняются; смету в ВКР привязать к дате.

## 9. Вывод
- Selectel — **полноценная замена AWS** для этой системы: Managed Kubernetes с Karpenter и прерываемыми нодами, та же видеокарта L4 24 ГБ, управляемые PostgreSQL и Redis, S3-совместимое хранилище. Архитектура и код не меняются, меняются только конфигурация Helm и Terraform.
- Минимальная конфигурация для демонстрации — **≈ 33 тыс. ₽/мес**, рабочая с одной круглосуточной L4 — **≈ 112 тыс. ₽/мес**.
- Предлагаю: для ВКР (РГРТУ, раздел о ситуации в РФ, 152-ФЗ) считать Selectel **основной площадкой для пользователей из России**, AWS — вариантом для зарубежной аудитории. Решение за мной, вопрос записан в [11](11_Решения_и_вопросы.md).
