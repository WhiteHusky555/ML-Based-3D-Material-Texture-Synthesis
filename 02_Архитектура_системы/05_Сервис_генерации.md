# Сервис генерации — diffusers (GPU-воркер)

## Почему генерация и апскейл в одном процессе
На слайде 7 это два сервиса на общей очереди `gpu`. Если запустить их двумя контейнерами, у каждого будет свой Celery-воркер, и они возьмут две задачи одновременно — две модели в видеопамяти, обещание «по одной» не выполнится.

Решение:
- **логически** — два сервиса: два модуля, две задачи Celery, два раздела в тексте ВКР;
- **физически** — один контейнер `gpu-worker`: `concurrency=1` (или `--pool=solo`), `worker_prefetch_multiplier=1`, `task_acks_late=True`.
Веса Real-ESRGAN занимают около 65 МБ, поэтому обе модели постоянно в памяти, перезагрузок нет.

## Пайплайн
- `StableDiffusionControlNetPipeline`, fp16, 20–30 шагов, планировщик DPM++ 2M или UniPC.
- Веса SD 1.5: оригинальный репозиторий runwayml удалён с Hugging Face → зеркало `stable-diffusion-v1-5/stable-diffusion-v1-5`. Веса — на volume.
- ControlNet: какой именно (depth / softedge / canny / tile) — по итогам курсовой.
- LoRA из курсовой: `load_lora_weights` + `fuse_lora`.
- **Циклический padding:** `padding_mode="circular"` у всех `Conv2d` в **UNet, ControlNet и декодере VAE**. Пропустить ControlNet или VAE — шов вернётся.
- `callback_on_step_end`: события прогресса по шагам и проверка флага отмены.
- Модели загружаются один раз при старте процесса (сигнал Celery `worker_process_init`; CUDA инициализируется после fork).

## Шаблон промпта
- Обязательные части добавляет шаблон: `seamless texture, top-down view, flat even lighting`, триггер-слово LoRA, negative prompt (`perspective, shadows, objects, text, watermark, …`).
- Длина ≤ 77 токенов CLIP.
- Шаблон и Pydantic-схемы — в общем Python-пакете (им пользуются и ассистент, и сервис генерации), версионируется вместе с LoRA.

## Тарифы
Модель **одна для всех тарифов** (SD 1.5 + ControlNet + LoRA из курсовой): автор не обучает несколько моделей. Премиум отличается настройками и готовыми дополнениями, а не другой моделью.
| | Бесплатный | Премиум |
|---|---|---|
| Шагов диффузии | 20 | 30–40 |
| Вариантов за запуск | 1 | до 4 (batch) |
| Референс-картинка (IP-Adapter, готовые веса) | нет | да |
| Приоритет в очереди | обычный | высокий |

Обоснование выбора модели и лицензий, загрузка референсов, 3D-моделей и своих LoRA — в [15_Модель_генерации_и_референсы.md](15_Модель_генерации_и_референсы.md).

## Интерфейс провайдера
`generate(control_image, slots, seed, params) → image`.
Коммерческий text-to-image API не даст ни LoRA, ни циклического padding. Поэтому «внешний провайдер» = тот же GPU-воркер на арендованной видеокарте или в Colab, подключённый к RabbitMQ. Код не меняется: Celery-воркеру всё равно, где он запущен. Брокер и MinIO тогда открываются наружу с TLS и паролями.
