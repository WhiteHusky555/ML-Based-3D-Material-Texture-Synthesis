# Веб-клиент — React + Three.js

## Сборка и раздача
- Vite + TypeScript; результат сборки раздаёт nginx как статику, отдельного Node-контейнера в работе нет.
- Состояние: TanStack Query (запросы к API), Zustand (параметры шума и форма).

## Экраны
| Экран | Что есть |
|---|---|
| Вход / регистрация | e-mail + пароль; восстановление пароля |
| Генератор (простой режим) | диалог в цепочке запросов: пресеты, модификаторы (мокрый, мшистый, старый), описание своими словами, всплывающие подсказки ассистента (премиум); результаты идут лентой, у каждого запроса — номер в аккаунте и код, кнопка «Уточнить» |
| Генератор (расширенный режим) | тип шума, масштаб, октавы, растяжение, seed, промпт на английском |
| Результат | 3D-просмотр, переключение карт, выбор движка, скачивание ZIP |
| История | список цепочек (название, дата, миниатюра); внутри — запросы с номерами, кодами, сроками хранения; переименование и удаление цепочки, открытие, удаление материала; «Поделиться» — ссылка на снимок, «Обновить снимок», «Закрыть доступ» |
| Опубликованная цепочка (гость, без входа) | снимок цепочки: описания, параметры, превью, 3D-просмотр; без скачивания; кнопка «Продолжить у себя» (без входа — сначала вход или регистрация) |
| Тариф / профиль | текущий тариф, остаток квоты на сегодня, оформление или отмена премиума |
| Панель администратора (роль admin) | пользователи (поиск, блокировка, ручной тариф), пресеты, версии модели, ссылка на технический мониторинг (Grafana) |
| Панель аналитика (роли analyst, owner) | отчёты «Использование», «Конверсия», «Генерации» за период, графики, выгрузка CSV; без персональных данных |
| Панель владельца (роль owner) | цены и лимиты тарифов, назначение и отзыв ролей сотрудников, финансовый отчёт, журнал аудита |

## Детали реализации
- **Превью шума:** сервер отдаёт одну плитку, сетку 3×3 клиент рисует сам (в 9 раз меньше трафика). Запрос при движении ползунка — с задержкой ~150 мс (debounce).
- **Подсказки к промпту:** запрос после паузы ~1 с в наборе; всплывающее окно поверх интерфейса; 1–3 варианта с кнопкой «Применить»; кнопка «скрыть». У бесплатного тарифа вместо подсказок — плашка «доступно в Премиум».
- **3D-просмотр:** react-three-fiber, `MeshStandardMaterial`: `map` (colorSpace = sRGB), `normalMap`, `roughnessMap`, `aoMap`, `displacementMap` (линейные). Кроме сферы — плоскость с повтором 3×3 и `RepeatWrapping`: на ней сразу виден шов, если он есть.
- **Прогресс:** через WebSocket — этап и шаг диффузии («генерация 14/25»).
- **Ограничения тарифа в интерфейсе:** недоступные опции (4K, больше шагов, несколько вариантов, референс-картинка) показываются с пометкой «Премиум», а не прячутся — это мотивирует к оформлению подписки. Окончательную проверку прав всё равно делает сервер.
- **Сеанс (BFF, решение 02.11.2026):** токенов в браузере нет — только cookie сеанса web-bff (`__Host-`, `HttpOnly`, `Secure`, `SameSite=Strict`). Все запросы идут на `/bff` того же источника; на изменяющих — заголовок `X-Requested-With: texgen`; на ответ `401` — экран входа. Панели персонала — отдельная сборка на `staff.<домен>` (staff-bff). Подробно — [17](17_Предложение_внедрения_BFF.md).
- **Панели персонала** показываются по роли из `GET /staff/me`; это только удобство интерфейса — права проверяет сервер на каждом запросе.
- **Публикация цепочки:** перед созданием ссылки — предупреждение «ссылку может открыть любой, у кого она есть»; страница снимка с `noindex`, адрес `/s/<токен>`. Подробно — [19](19_Запросы_цепочки_и_публикация.md).
