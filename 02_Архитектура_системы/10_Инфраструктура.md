# Инфраструктура: готовые сервисы

## RabbitMQ
- Брокер для Celery: очереди `gpu` и `cpu` (durable).
- **Приоритетная очередь** `gpu` (`x-max-priority`): премиум-задачи берутся раньше бесплатных. Celery поддерживает приоритет задач с RabbitMQ.
- Topic-exchange `job.events` — события статусов для API-сервиса.
- Dead-letter очередь: туда попадает задача, упавшая после N повторов; её видно в веб-интерфейсе управления (плагин management).

## PostgreSQL
- Схемы:
  - `users` — сервис пользователей и тарифов;
  - `core` — API-сервис (материалы, этапы, артефакты, пресеты);
  - `assistant` — по желанию: кэш ответов и статистика подсказок.
- Параметры материала — `jsonb` + уникальный индекс по хэшу.
- Миграции — Alembic в каждом сервисе для своей схемы.

## MinIO (S3)
- Бакеты: `noise`, `raw`, `textures`, `archives`.
- Промежуточные (`noise`, `raw`) — правило жизненного цикла: удаление через 1–2 дня.
- Итоговые материалы — по сроку тарифа (7 / 90 дней); удаление делает периодическая задача API-сервиса, чтобы БД и хранилище не расходились.
- Скачивание — presigned-ссылки через отдельный хост `s3.localhost` в nginx (без переписывания пути, иначе подпись не сойдётся).

## Ollama
- Рантайм языковой модели ассистента, по умолчанию на CPU.
- OpenAI-совместимый API, structured output по JSON-схеме.
- `keep_alive`, чтобы модель не выгружалась между запросами.

## Мониторинг (по желанию)
- **Flower** — очереди и задачи Celery.
- **Prometheus + Grafana + экспортёр метрик NVIDIA** — загрузка GPU, видеопамять; графики для главы с экспериментами. Доступ к Grafana — администратору и владельцу (вход через сервис пользователей по роли).
- Бизнес-метрики для монетизации: регистрации, конверсия в премиум, генерации по тарифам.

## Docker Compose — локальная разработка
Docker Compose остаётся для ежедневной разработки: быстрее цикл «правка → запуск», проще GPU на рабочем компьютере. Образы те же, что в Kubernetes.
- GPU-воркеру: `deploy.resources.reservations.devices` (driver: nvidia, capabilities: [gpu]); на Windows — Docker Desktop с WSL2.
- Профили: базовый стек, `gpu`, `monitoring`.
- Healthcheck + `depends_on: condition: service_healthy` — сервисы не стартуют раньше базы и брокера.
- Volumes: веса моделей (кэш Hugging Face), `NUMBA_CACHE_DIR`, данные PostgreSQL, MinIO, Ollama.
- Секреты (ключ подписи JWT, пароли БД, ключи платёжки) — через `.env`, не в репозитории.
