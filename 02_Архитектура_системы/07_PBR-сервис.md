# PBR-сервис — NumPy + OpenCV (очередь cpu)

## Карты
| Карта | Как считается |
|---|---|
| **Height** | шум в итоговом разрешении + высокочастотная составляющая яркости albedo (мелкий рельеф); веса — из пресета. Сохранять **16-битным PNG** — в 8 битах displacement даёт ступеньки |
| **Normal** | градиенты height через `np.roll` (бесшовно сами по себе), параметр силы |
| **Roughness** | базовое значение пресета + вариации по яркости; модификатор «мокрый» снижает, «мшистый» повышает |
| **AO** | разность height и его размытий на нескольких радиусах (cavity) |
| Metallic | константа пресета (0 для камня, дерева, глины; маска для металлов) |

## Бесшовность фильтров
Многие функции OpenCV не принимают `BORDER_WRAP`, поэтому везде одна схема: `np.pad(mode="wrap")` → фильтр → обрезка.

## Упаковка под движки
| Движок | Что в архиве |
|---|---|
| Blender | отдельные карты; albedo — sRGB, остальные — Non-Color; нормали OpenGL (Y+) |
| Unity URP | Metallic map (R — metallic, A — smoothness = 1 − roughness); нормали OpenGL |
| Unity HDRP | Mask map (R — metallic, G — AO, B — detail mask, A — smoothness) |
| Unreal Engine | ORM (R — AO, G — roughness, B — metallic); нормали **DirectX** — зелёный канал инвертируется |

В каждый ZIP — `manifest.json` со всеми параметрами (материал можно воспроизвести).
