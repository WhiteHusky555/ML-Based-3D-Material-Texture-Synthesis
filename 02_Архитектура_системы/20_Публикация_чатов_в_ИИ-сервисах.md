# Как устроена публикация чатов по ссылке в популярных ИИ-сервисах

Проверено 01.11.2026 по справке сервисов (ссылки — в конце). Нужно для решения о публикации цепочек запросов в нашей системе ([19](19_Запросы_цепочки_и_публикация.md)).

## ChatGPT (OpenAI)
- **Что публикуется.** Разговор целиком или один ответ ассистента; в ссылку могут попасть поддерживаемые картинки и загруженные файлы. Отдельно можно делиться запланированными задачами.
- **Снимок.** Ссылка из личного аккаунта содержит то, что было в разговоре на момент создания или обновления ссылки; новые сообщения сами не добавляются. Обновить снимок — «Share → Update link».
- **Кто видит.** Любой, у кого есть ссылка; аккаунт для просмотра не нужен. Ограничить конкретными людьми нельзя. В рабочих пространствах Business / Enterprise / Edu ссылку открывают только участники того же пространства, и там она может включать сообщения, добавленные после публикации.
- **Продолжение.** Получатель может продолжить разговор: продолжение создаёт отдельный приватный разговор в аккаунте получателя.
- **Автор.** Ссылки анонимны по умолчанию; в старых вариантах могло показываться имя автора.
- **Управление.** Settings → Data controls → Shared links → Manage: список ссылок, удаление одной или всех. Срок действия задать нельзя.
- **Отзыв.** Удаление ссылки прекращает доступ по ней, но не удаляет разговоры, которые получатели уже сохранили у себя. Удаление исходного разговора удаляет и ссылку; удаление аккаунта удаляет ссылки на разговоры.
- **Поисковики.** Страницы ссылок не предназначены для индексации, но это не делает ссылку приватной: её могут переслать.
- **Безопасность.** Адреса ссылок начинаются с `https://chatgpt.com/share/`; есть кнопка «Report conversation». Справка советует не публиковать медицинские, финансовые данные и пароли.

## Claude (Anthropic)
- **Что публикуется.** Снимок чата: все сообщения до момента публикации, включая артефакты. Вложенные файлы в снимок не входят. Сырые данные вызовов MCP-инструментов не показываются — только итоговые ответы.
- **Снимок.** Сообщения после публикации остаются приватными. Чтобы обновить снимок, публикацию отключают и включают снова.
- **Кто видит.** Любой, у кого есть ссылка; аккаунт Claude не нужен. Ограничить конкретными людьми нельзя. На тарифах Team / Enterprise чаты видят только вошедшие участники той же организации.
- **Продолжение.** Нет: публичная ссылка только для просмотра, продолжить чат по ней нельзя.
- **Управление.** Settings → Privacy → Shared chats: список опубликованных чатов (название, дата, ссылка), кнопка отмены публикации.
- **Отзыв.** Перевод чата в «Private» — ссылка перестаёт работать сразу. Копии, скриншоты и архивы, которые кто-то уже сделал, не удаляются.
- **Поисковики.** Каждая страница помечена `noindex`; каталога или карты сайта общих чатов нет; ссылка — длинная случайная строка, её не угадать. При этом справка прямо советует считать публичную ссылку публичной: если её выложат на форум, её прочитает любой.

## Gemini (Google)
- **Что публикуется.** Вся переписка; загруженные в чат картинки доступны в общем чате, их можно скачать. Если в чате использовался Gem, можно делиться с его инструкциями или без них.
- **Кто видит.** Любой, у кого есть ссылка (`g.co/gemini/share/…`); её можно переслать дальше или опубликовать в соцсетях.
- **Продолжение.** Получатель может продолжить чат у себя кнопкой «Continue this chat» (кроме чатов с Gems и пользователей младше 18 лет). Если чат создан пользователем с подпиской Google AI, продолжить можно только с подпиской. При включённой истории активности общий чат сохраняется в истории получателя.
- **Управление и отзыв.** Settings & help → Your public links: удаление ссылки или всех ссылок сразу; есть жалоба на общий чат.

## Что взято в нашу систему
- **Снимок с обновлением по тому же адресу** — как «Update link» в ChatGPT.
- **Просмотр без аккаунта, автор не показывается** — как во всех трёх сервисах и анонимные ссылки ChatGPT.
- **«Продолжить у себя» — отдельная копия в аккаунте получателя** — как ChatGPT и Gemini. Ограничение Gemini для чатов подписчиков у нас заменено проверкой прав тарифа: параметры, недоступные получателю, показываются до запуска генерации.
- **Файлы не отдаются**: гость видит превью и 3D, карты не скачиваются — ближе к Claude (вложения не входят); причина — коммерческая лицензия премиум-материалов.
- **Отзыв действует сразу, копии остаются** — как во всех трёх сервисах.
- **Защита ссылки**: `noindex`, случайный токен 128 бит, в БД хранится только его хэш, каталога ссылок нет — как у Claude, плюс хранение хэша вместо токена.
- **Предупреждение при публикации** — «ссылку может открыть любой, у кого она есть» (совет Claude считать публичную ссылку публичной).
- **Не взято**: срок действия ссылки и список получателей — их нет ни в одном из сервисов; при необходимости добавляются позже.
