# LLM-провайдеры для подсказок к промпту

Решение (14.10.2026): языковая модель для подсказок — **либо локальная, либо через OpenRouter**. Нужен список провайдеров, в том числе российских.
Сведения собраны 14.10.2026; цены и версии моделей меняются быстро — перепроверить перед реализацией.

## 1. Требования к провайдеру
1. **Structured output по JSON-схеме** — без этого ответ нельзя надёжно проверить.
2. Хорошее понимание **русского** (описания пишут по-русски) и умение писать **английские** промпты.
3. Низкая задержка (подсказка должна прийти за секунды) и низкая цена: запросы короткие — сотни токенов.
4. Желательно **OpenAI-совместимый API** — тогда один клиент на всех провайдеров.

## 2. Как устроено в коде
Интерфейс `LLMProvider.suggest(context) → Suggestions`. Реализации:
- **`OpenAICompatibleProvider`** — один класс на всех, у кого OpenAI-совместимый API: Ollama, vLLM, OpenRouter, OpenAI и т. п. Различаются только `base_url`, `api_key`, `model`.
- **`GigaChatProvider`** — отдельный адаптер (у GigaChat свой формат авторизации).
- Выбор провайдера — переменными окружения; можно задать **разные провайдеры для разных тарифов** (премиуму — сильнее модель) и **резервный провайдер** на случай отказа основного.

## 3. Варианты

### A. Локальная модель (в своём кластере)
| Рантайм | Плюсы | Минусы |
|---|---|---|
| **Ollama** | проще всего; OpenAI-совместимый API; JSON-схема через `format` | под высокую нагрузку слабее vLLM |
| **vLLM** | высокая пропускная способность, батчинг, OpenAI-совместимый API, структурированный вывод | нужен GPU |
| llama.cpp server | работает на CPU, ограничение вывода грамматикой / JSON-схемой | меньше удобств |

Открытые модели с хорошим русским (по обзорам 2026 г.):
| Модель | Разработчик | Лицензия | Комментарий |
|---|---|---|---|
| **Qwen** (разные размеры) | Alibaba | открытая (проверять версию) | хорошо понимает русский «из коробки» |
| **T-Lite / T-Pro 2.0** | Т-Технологии (Т-Банк) | Apache 2.0 | русскоязычные дообучения; T-Lite — маленькая, подходит для подсказок |
| **GigaChat 3 / 3.1** (открытые веса) | Сбер | MIT | можно развернуть у себя |
| **YandexGPT 5 Lite** (открытые веса) | Яндекс | открытая (проверить условия) | облегчённая модель, контекст 32k |
| Vikhr, Saiga | сообщество | открытые | дообучения под русский |
| Cotype Light 3 (9B, ~18 ГБ VRAM) | MWS AI (ex-MTS AI) | по запросу, on-prem | корпоративный формат |

**Где запускать в нашей системе:** на CPU-узле (модель 3–4B, 5–20 с на ответ) или на том же GPU-узле g6.xlarge (L4 24 ГБ — рядом с SD останется место под 3–8B модель, ответ 1–2 с).

### B. OpenRouter — агрегатор облачных моделей
- Один ключ и **OpenAI-совместимый API** к сотням моделей разных компаний.
- Structured output: `response_format` с `type: "json_schema"` и `strict: true`. Поддерживают **не все модели** — фильтр `require_parameters: true` отсекает провайдеров без поддержки. Функция появилась в декабре 2024 г. и расширялась по провайдерам.
- Есть бесплатные модели с лимитами частоты — подойдут для разработки.
- Плюс: не нужен свой GPU/CPU под LLM, можно менять модель одной настройкой.
- Минус: тексты пользователей уходят внешнему провайдеру; зависимость от внешнего сервиса; оплата в валюте.

### C. Прямые облачные API (зарубежные)
| Провайдер | Пример цен за 1 млн токенов | Комментарий |
|---|---|---|
| OpenAI | самые дешёвые: GPT-4.1 Nano $0,10 / $0,40; GPT-5.6 Luna $0,20 / $1,20 (после снижения 30.07.2026) | эталон по structured output |
| Google Gemini | Gemini 2.5 Flash $0,30 / $2,50 | быстрые лёгкие модели |
| Anthropic Claude | Claude Haiku 4.5 $1 / $5 | дороже для этой задачи |
| Qwen через облачных провайдеров | Qwen3-235B-A22B ~$0,09 / $0,10 | очень дёшево |

Подсказка — около 500 токенов на вход и 150 на выход. Даже на дешёвых моделях это доли цента: **цена LLM в экономике сервиса несущественна**, главная статья — GPU для диффузии.

### D. Российские облачные API
| Провайдер | Что есть | Особенности |
|---|---|---|
| **GigaChat API** (Сбер) | линейка GigaChat (Lite / Pro / Max, новые поколения 3.x); токены — от ~0,065 ₽ за 1000 (по обзору, август 2026 г.) | свой формат API: OAuth-токен по ключу авторизации → нужен отдельный адаптер; может понадобиться корневой сертификат НУЦ Минцифры для TLS; регистрация через Сбер ID; оплата в рублях, данные в РФ |
| **Alice AI / YandexGPT API** (Яндекс) | модели Яндекса через Yandex Cloud | облачная платформа Yandex **исключена**; открытые веса YandexGPT 5 Lite можно запускать у себя (вариант A) |
| **Cotype** (MWS AI) | Cotype Pro 3 / Light 3 (июль 2026 г.) | в основном развёртывание в контуре заказчика, по запросу |

**Для ВКР:** российских провайдеров уместно упомянуть в разделе о ситуации в РФ. Практичнее всего — **открытые веса** (T-Lite / T-Pro, GigaChat 3.x) в своём кластере: не зависят от регистрации и оплаты, данные не покидают систему.

## 4. Рекомендация
| Окружение | Провайдер |
|---|---|
| Разработка | OpenRouter (бесплатная или дешёвая модель с JSON-схемой) или Ollama локально |
| Бесплатный тариф | подсказок нет (или пробный лимит) |
| Премиум | основной: локальная модель (vLLM/Ollama, Qwen или T-Lite) на GPU-узле; резервный: OpenRouter |
| Эксперимент ВКР | сравнить 3–4 провайдера: локальная 3–4B, локальная 7–8B, облачная через OpenRouter, GigaChat — по времени ответа, доле ответов по схеме, доле принятых подсказок |
