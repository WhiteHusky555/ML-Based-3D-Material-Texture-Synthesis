# Аналоги: генерация текстур и материалов по текстовому описанию

Сбор сведений: 14.10.2026. Источники — в файле [Источники.md](Источники.md).
Пример, от которого шли: Meshy AI Texture Generator (ссылку дал руководитель/сам автор ВКР).

## 1. Классификация аналогов

| Класс | Что делает | Примеры | Файлы |
|---|---|---|---|
| **Генераторы материалов** (material generators) | По тексту/картинке выдают отдельный бесшовный материал, который потом накладывают на модель | Polycam, Scenario, 3DTexel, Boracity, WithPoly, ArmorLab, Unity Material Generator, Substance 3D Sampler | 02–09 |
| **Текстурирование модели** (mesh-aware) | Рисуют текстуру сразу по UV-развёртке конкретной 3D-модели | Meshy, Tripo3D, Rodin (Hyper3D) | 01, 10 |
| **Открытые локальные решения** | Stable Diffusion у себя на компьютере, в т. ч. внутри Blender | Dream Textures, ArmorLab, SD WebUI / ComfyUI с режимом tiling | 09, 11 |
| **Image → PBR утилиты** | Не генерируют текстуру, а считают PBR-карты из готовой картинки | AITextured, 3D AI Studio PBR Map Generator, Sorceress Material Forge (второй шаг) | 12 |
| **Генеративные модели общего назначения** | Любые картинки по тексту; бесшовность и PBR — только «уговорами» в промпте | Nano Banana, Kandinsky, Шедеврум | 13 |

Разделение «генератор материала» vs «текстурирование модели» взято из сравнения Meshy (блог, 2026): ни один подход не лучше, они решают разные задачи.
**Наша система — генератор материалов** (бесшовный набор PBR-карт, без привязки к модели).

## 3. Выводы для ВКР

1. **Рынок подтверждает актуальность.** В 2024–2026 гг. генерацию бесшовных PBR-материалов по тексту добавили крупные игроки: Adobe (Sampler 4.4, май 2024), Unity (Material Generator, май 2026), а также специализированные сервисы (Polycam, Scenario, Meshy). Это прямой аргумент для раздела «Актуальность».
2. **Новизна — управление формой.** Почти все аналоги управляются только текстом и картинкой-референсом. Ближе всего к нашей идее Unity Pattern Reference (картинка задаёт структурный узор) и эскиз в Scenario. Ни один найденный сервис не даёт **параметрического** управления формой (тип шума, масштаб, октавы, seed) с мгновенным превью.
3. **Бесшовность.** У облачных генераторов она обеспечивается моделью или пост-обработкой («Fix Seams», «Enhance Seamless» второй проход ИИ по краям у 3DTexel). У нас — по построению на каждом этапе: периодический шум → циклический padding в диффузии → wrap-апскейл → wrap-фильтры PBR.
4. **Помощник промптов оправдан.** У Scenario есть Prompt Spark — расширяет короткую идею, переводит, делает промпт из картинки. Значит, совет добавить ассистента соответствует практике рынка. Отличие нашего: подсказка может предложить не только текст, но и **пресет процедурного шума** (форму материала).
5. **Модель распространения.** Как у Meshy и Polycam: облачный сервис с бесплатным тарифом и премиумом (4K, больше шагов и вариантов, референсы, подсказки к промпту, долгое хранение). Отличие от облачных аналогов — открытая архитектура на Kubernetes: ту же систему можно развернуть у себя. Из найденных локально работают только ArmorLab и Dream Textures; Dream Textures даёт только цветовую текстуру без PBR-набора.
6. **Для текста ВКР** из сравнения берём таблицу критериев (раздел 2) как основу главы «Анализ аналогов». Перед сдачей перепроверить цены и тарифы — они меняются быстрее всего.
