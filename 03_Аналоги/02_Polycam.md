# Polycam AI Texture Generator

- **Сайт:** https://poly.cam/tools/ai-texture-generator
- **Класс:** генератор материалов (бесшовные текстуры)
- **Компания:** Polycam — в первую очередь приложение для 3D-сканирования
- **Дата сведений:** 14.10.2026

## Что делает
- Вводится текстовый промпт → сервис выдаёт несколько **бесшовных (tileable)** текстур, пользователь выбирает и скачивает.
- Настройки (со страницы сервиса):
  - загрузка изображения-референса для стиля и ползунок **image strength** (насколько строго следовать картинке, по умолчанию 0.2);
  - разрешение: **512, 768, 1024, 1536, 2048 px**;
  - количество вариантов: **2, 4, 6, 8**.
- По данным обзоров (блог Meshy, Lovart, 2026): модель обучена на **реальных отсканированных поверхностях**, вместе генерируются base color, normal, roughness, metallic, displacement; хорошо держит бесшовность на камне, дереве, бетоне.

## Цена
- Бесплатно при наличии аккаунта Polycam (по обзору Lovart).

## Чем отличается от нашей системы
- Форма управляется только текстом и референсом; параметров формы нет.
- Облачный сервис.
- Нет помощника промптов: совет сервиса — «делайте промпт подробнее и генерируйте снова».

## Что взять в ВКР
- Выбор числа вариантов и разрешения — полезная идея для интерфейса (сейчас у нас один результат 512² → 2048²).
- Обучение на сканах — аргумент, почему у нас LoRA дообучается на ambientCG (тоже реальные сканы).
