# Unity Material Generator (Unity AI Generators)

- **Блог Unity, 14.05.2026:** https://unity.com/blog/unity-ai-material-generator
- **Класс:** генератор материалов внутри игрового движка
- **Статус:** бета (AI tools in beta)
- **Дата сведений:** 14.10.2026

## Что делает
- Часть набора **Generators** — ИИ-инструментов создания ассетов прямо в редакторе Unity.
- Создаёт реалистичные **бесшовные (tileable)** PBR-материалы по текстовому промпту и, по желанию, по референс-картинкам.
- Поле **Pattern Reference**: картинка, задающая **структурный узор** материала. В пакет входят готовые текстуры `pattern_##`, оптимизированные для бесшовной укладки; с ними лучше всего получаются повторяющиеся поверхности — кирпич, плитка, ткань.
- Результаты появляются в панели Generations; при наведении видны модель и настройки промпта.

## Почему это самый близкий аналог по идее
**Pattern Reference = «форма задаётся отдельным изображением, фактура — текстом».** У нас то же разделение, только узор не выбирается из готовых картинок, а **строится процедурным шумом с параметрами** (тип, масштаб, октавы, растяжение, seed) и подаётся в ControlNet.

| | Unity Pattern Reference | Наша система |
|---|---|---|
| Источник формы | готовая картинка-узор | процедурный шум, генерируется на лету |
| Изменение формы | заменить картинку | ползунки, мгновенное превью |
| Бесшовность узора | подготовленные `pattern_##` | периодичность шума по построению |
| Где работает | в редакторе Unity, облачная генерация | отдельное веб-приложение, локально |

## Что взять в ВКР
- Ключевой аргумент: в 2026 г. Unity пришла к той же идее управления структурой материала отдельным входом — значит, подход востребован.
- Отличие и новизна нашей работы — параметрический и бесшовный по построению источник формы.
