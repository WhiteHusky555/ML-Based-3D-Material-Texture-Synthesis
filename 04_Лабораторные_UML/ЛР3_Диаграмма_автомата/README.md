# ЛР3. Диаграмма автомата

Источники: [5] гл. 3 (с. 30–34); [6] гл. 13 (интерфейс StarUML).
Предметная область — та же система генерации бесшовных PBR-материалов; модель продолжает проект ЛР1–ЛР2.

## Задание и требования методички ([5], гл. 3)
- [x] Автоматы строятся **поакторно**: сначала сценарий работы актора с системой (верхний уровень, с выбором варианта использования), затем алгоритмы реализации вариантов использования, затем декомпозиция.
- [x] Вспомогательные прецеденты — состояниями с одноимёнными внутренними деятельностями (как рис. 3.2–3.4 [5]) или ссылочными состояниями.
- [x] Состояния с внутренними деятельностями `entry/`, `do/`, `exit/`; бесконечная деятельность (ожидание) завершается только **событиями**.
- [x] Надписи переходов: событие, `[сторожевое условие]`, `/ действие на переходе`; на одной из ветвей выбора — `[else]`.
- [x] Внутренние переменные (`Выход`, `Статус`, `Попытка`, `Объект` и др.) — атрибуты вспомогательного объекта потока управления (рис. 3.5 [5]); указаны в документировании автоматов.
- [x] Декомпозиция выполнена для состояния, чья деятельность не исчерпывается названием («обработка» → автомат «Обработка задачи генерации»); для простых — указано, что отдельная диаграмма не нужна.
- [x] Подрисуночные подписи — название сценария или алгоритма.
- [x] Документирование всех диаграмм и элементов (Documentation) и перенос в отчёт.
