## Автомат «Сценарий работы пользователя с системой»

Сценарий использования системы пользователем и премиум-пользователем (наследует сценарий по генерализации): вход, выбор варианта использования в главном окне, чередование вариантов использования до выхода. Различия премиум-тарифа реализованы сторожевыми условиями внутри автоматов прецедентов. Внутренние переменные (атрибуты вспомогательного объекта потока управления): Выход (Boolean) — признак завершения работы сотрудником или пользователем; False — работа продолжается, True — выбран выход.

Диаграмма `D_User_Scenario`. Автомат верхнего уровня для акторов «Пользователь» и «Премиум-пользователь»: каждый вариант использования, ассоциированный с актором, представлен ссылочным состоянием; выбор варианта — цепочкой псевдосостояний выбора.

Количественная характеристика диаграммы: простых состояний — 2; ссылочных состояний — 6; псевдосостояний выбора — 6; соединения — 5; начальных — 1; конечных — 2; переходов — 26.

- **Заблокирована** (do/Отклонение запросов). Простое состояние: учётная запись заблокирована администратором; все запросы отклоняются. Деятельности состояния семантически просты, отдельная диаграмма не приводится.

### Переходы

- Стрелка перехода из начального псевдосостояния в «Адрес не подтверждён» не содержит надписей: переход выполняется сразу при запуске автомата и является безальтернативным.
- Над стрелкой перехода из «Адрес не подтверждён» в «Активна» указаны: событие «переход по ссылке подтверждения»; внутренняя деятельность состояния «Адрес не подтверждён» потенциально бесконечна (ожидание действия или внешнего события), поэтому выход из него возможен только по событию.
- Над стрелкой перехода из «Активна» в «Вход заблокирован» указаны: событие «5 неудачных попыток входа»; внутренняя деятельность состояния «Активна» потенциально бесконечна (ожидание действия или внешнего события), поэтому выход из него возможен только по событию.
- Над стрелкой перехода из «Вход заблокирован» в «Активна» указаны: событие «прошло 15 минут»; внутренняя деятельность состояния «Вход заблокирован» потенциально бесконечна (ожидание действия или внешнего события), поэтому выход из него возможен только по событию.
- Над стрелкой перехода из «Активна» в «Заблокирована» указаны: событие «заблокирована администратором», действие на переходе «Версия += 1»; внутренняя деятельность состояния «Активна» потенциально бесконечна (ожидание действия или внешнего события), поэтому выход из него возможен только по событию; действие выполняется при переходе и изменяет внутреннюю переменную или состояние объекта.
- Над стрелкой перехода из «Заблокирована» в «Активна» указаны: событие «разблокирована»; внутренняя деятельность состояния «Заблокирована» потенциально бесконечна (ожидание действия или внешнего события), поэтому выход из него возможен только по событию.
