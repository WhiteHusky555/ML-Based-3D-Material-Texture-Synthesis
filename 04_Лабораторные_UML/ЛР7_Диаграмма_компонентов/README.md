# ЛР7. Диаграмма компонентов

Источники: [8] с. 21–34; [1, 3, 4].

Статус: не начато.

## Что моделировать в системе из ВКР (предварительно)
- Компоненты = сервисы из `02_Архитектура_системы`: nginx, веб-клиент, API-сервис, сервис пользователей, процедурный сервис, GPU-воркер, PBR-сервис, ассистент, RabbitMQ, PostgreSQL, S3, LLM-провайдер.
- Интерфейсы: REST/WebSocket, AMQP, S3 API, OpenAI-совместимый API.
- Общий Python-пакет (шаблон промпта, схемы) — отдельный компонент-библиотека.

Требования к оформлению — уточнить по соответствующей главе методички перед началом работы.
