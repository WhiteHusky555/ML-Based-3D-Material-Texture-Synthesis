## Состояние
- На компьютере StarUML **не установлен** (проверено 14.10.2026).
- Методичка описывает **StarUML 5.0** (классическая версия для Windows):
  - модель строится в Model Explorer, диаграммы прецедентов — в **Use Case View**;
  - текстовые описания прикрепляются редактором вложений во вкладке **Attachment**;
  - работник (worker): Add → Class, стереотип worker, Format → Stereotype Display → Iconic, затем Suppress Attributes / Suppress Operations.
- **Осторожно с номером версии.** «StarUML 5.0» — это два разных продукта:
  1. **старый открытый StarUML 5.0** (Windows, 2005–2006, SourceForge) — именно его интерфейс описан в методичке и у Каюмовой;
  2. **новый StarUML от MKLab** (Electron, кроссплатформенный) — у него тоже были версии 5.0.x в 2022 г., сейчас актуальна **7.1.1** (сентябрь 2026). Другой интерфейс, нет вкладки Attachment, лицензия — пробный период 30 дней, дальше платно (EULA).

### Установленная версия (14.10.2026)
- Автор установил **StarUML 6.3.3** в `C:\Program Files\StarUML` из архива `StarUML 6.3.3 [FileCR].zip`.
- FileCR — неофициальный сайт со взломанными сборками; такие сборки могут содержать вредоносный код. Claude этот exe не запускает. Безопаснее официальный установщик с https://staruml.io/download (тот же 6.x, пробный режим).
- Проекты для 6.x — формат `.mdj`; для 5.0 — `.uml`. Генерируются оба.

### Установка (делает автор)
1. Распаковать архив (лучше не в эту папку, а, например, в `Загрузки`).
2. Запустить `StarUML_5.0/staruml-5.0-with-cm.exe`, установить с настройками по умолчанию.
3. При первом запуске выбрать шаблон проекта (Default Approach — с папками Use Case View, Logical View и т. д.).
