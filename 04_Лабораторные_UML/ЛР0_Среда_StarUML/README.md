## Версии StarUML
Методичка описывает **StarUML 5.0** (классическая версия для Windows):
- модель строится в Model Explorer, диаграммы прецедентов — в **Use Case View**;
- текстовые описания прикрепляются редактором вложений во вкладке **Attachment**;
- работник (worker): Add → Class, стереотип worker, Format → Stereotype Display → Iconic, затем Suppress Attributes / Suppress Operations.

«StarUML 5.0» — это два разных продукта:
1. **старый открытый StarUML 5.0** (Windows, 2005–2006, SourceForge) — его интерфейс описан в методичке и у Каюмовой;
2. **StarUML от MKLab** (Electron, кроссплатформенный) — у него тоже были версии 5.0.x в 2022 г.; другой интерфейс, нет вкладки Attachment.

Отличия StarUML 6, учтённые в проектах: стереотипа worker с иконкой нет — работники показаны классами с подписью «worker»; вкладки Attachment нет — тексты сценариев приложены к отчёту.

### Установка StarUML 5.0
1. Распаковать архив.
2. Запустить `StarUML_5.0/staruml-5.0-with-cm.exe`, установить с настройками по умолчанию.
3. При первом запуске выбрать шаблон проекта Default Approach (папки Use Case View, Logical View и т. д.).
