## Пакеты и классы

### Пакет «Сущности» — 27 классов

Классы-сущности (entity): носители информации с длинным жизненным циклом; соответствуют таблицам базы данных и полям JSON.

#### Пользователь (класс-сущность)

Учётная запись человека, работающего с системой: пользователя или сотрудника. Корень агрегата: статус, роль, счётчик неудачных входов и версия токенов меняются только его операциями — переходами автомата ЛР3 «Жизненный цикл учётной записи». На ней основаны авторизация на сервере и мгновенный отзыв доступа. Хранится в таблице users. Ограниченный контекст — «Учётные записи и доступ».

Атрибуты:

- `-ид: UUID` — Первичный ключ; UUID не позволяет перебирать идентификаторы в адресах API.
- `-email: str` — Адрес электронной почты — логин; уникален, хранится в нижнем регистре. Тип str — строка (текст).
- `-хэшПароля: str` — Хэш пароля Argon2id; сам пароль не хранится. Тип str — строка (текст).
- `-роль: Роль` — Роль для проверки прав на сервере при каждом запросе.
- `-статус: СтатусУчётнойЗаписи` — Состояние учётной записи (автомат ЛР3 «Жизненный цикл учётной записи»). Тип СтатусУчётнойЗаписи — перечисление «СтатусУчётнойЗаписи» (допустимы только его значения).
- `-версияТокенов: int` — Версия токенов; увеличение делает недействительными все выданные токены (переменная «Версия» ЛР3). Тип int — целое число (счётчик, номер или размер).
- `-неудачныхПопыток: int` — Число неудачных попыток входа за 15 минут (переменная «Неудачных попыток» ЛР3). Тип int — целое число (счётчик, номер или размер).
- `-входЗаблокированДо: datetime` — Окончание временной блокировки входа; пусто, если вход разрешён. Тип datetime — дата и время в UTC (момент события).
- `-создан: datetime` — Дата и время регистрации. Тип datetime — дата и время в UTC (момент события).

Операции:

- `+ПроверитьПароль(пароль: str): bool` — Сверяет пароль с хэшем; время проверки не зависит от результата. Параметры: пароль — строка (текст); результат bool — логическое значение «да/нет».
- `+ВходРазрешён(сейчас: datetime): bool` — Можно ли войти: учётная запись активна и временная блокировка истекла. Параметры: сейчас — дата и время в UTC (момент события); результат bool — логическое значение «да/нет».
- `+ПодтвердитьАдрес(): None` — Переход «Адрес не подтверждён» → «Активна» по ссылке подтверждения. Результата нет (None): операция только изменяет состояние.
- `+ЗафиксироватьНеудачныйВход(сейчас: datetime): None` — Увеличивает счётчик неудачных попыток; на пятой блокирует вход на 15 минут (переход «Активна» → «Вход заблокирован»). Правило блокировки живёт только здесь. Параметры: сейчас — дата и время в UTC (момент события); результата нет (None): операция только изменяет состояние.
- `+СброситьСчётчикПопыток(): None` — Обнуляет счётчик после успешного входа. Результата нет (None): операция только изменяет состояние.
- `+Заблокировать(): None` — Блокировка администратором (переход в «Заблокирована») с отзывом всех токенов. Результата нет (None): операция только изменяет состояние.
- `+Разблокировать(): None` — Снятие блокировки администратором (переход «Заблокирована» → «Активна»). Результата нет (None): операция только изменяет состояние.
- `+СменитьПароль(хэшПароля: str): None` — Новый хэш пароля и отзыв всех выданных токенов. Параметры: хэшПароля — строка (текст); результата нет (None): операция только изменяет состояние.
- `+НазначитьРоль(роль: Роль): None` — Новая роль действует со следующего запроса; выданные токены отзываются. Параметры: роль — перечисление «Роль» (допустимы только его значения); результата нет (None): операция только изменяет состояние.
- `-ОтозватьТокены(): None` — Увеличивает версию токенов; вызывается блокировкой, сменой пароля и роли. Результата нет (None): операция только изменяет состояние. Закрытая (-): вспомогательный шаг, вызывается только внутри класса.

#### Роль (перечисление)

Перечисление ролей учётной записи; роль читается на сервере при каждом запросе. Ограниченный контекст — «Учётные записи и доступ».

Значения:

- `+пользователь` — Работа с материалами и подпиской (бесплатный или премиум-тариф).
- `+администратор` — Техническое обслуживание: пользователи, пресеты, модели, мониторинг.
- `+аналитик` — Только агрегированные показатели без персональных данных.
- `+владелец` — Цены и лимиты тарифов, роли сотрудников, финансы, журнал аудита.

#### СтатусУчётнойЗаписи (перечисление)

Перечисление состояний учётной записи — состояния автомата ЛР3 «Жизненный цикл учётной записи». Ограниченный контекст — «Учётные записи и доступ».

Значения:

- `+адресНеПодтверждён` — Учётная запись создана, адрес не подтверждён.
- `+активна` — Вход и работа разрешены.
- `+входЗаблокирован` — Вход временно заблокирован после 5 неудачных попыток.
- `+заблокирована` — Учётная запись заблокирована администратором.

#### Тариф (класс-сущность)

Тариф обслуживания — бесплатный или премиум. Корень агрегата с версиями: права хранятся данными, поэтому лимиты меняются без перевыпуска кода, а каждое изменение условий сохраняет новую версию. Хранится в таблице plans. Ограниченный контекст — «Тарифы и оплата».

Атрибуты:

- `-код: str` — Уникальный код тарифа (free или premium); первичный ключ. Тип str — строка (текст).
- `-название: str` — Название для интерфейса. Тип str — строка (текст).
- `-цена: Деньги` — Цена за оплаченный период. Тип Деньги — объект класса «Деньги».
- `-период: int` — Длительность оплаченного периода в днях. Тип int — целое число (счётчик, номер или размер).
- `-права: ПраваТарифа` — Действующие права тарифа. Тип ПраваТарифа — объект класса «ПраваТарифа».
- `-версии: list[ВерсияТарифа]` — История условий тарифа (части агрегата). Тип list[ВерсияТарифа] — список объектов класса «ВерсияТарифа».

Операции:

- `+ИзменитьУсловия(цена: Деньги, права: ПраваТарифа, изменил: UUID): None` — Меняет цену и права и добавляет новую версию; прежние версии не меняются. Версии создаёт только корень. Параметры: цена — объект класса «Деньги»; права — объект класса «ПраваТарифа»; изменил — UUID (уникальный идентификатор, который нельзя подобрать перебором); результата нет (None): операция только изменяет состояние.

#### ВерсияТарифа (класс-сущность)

Объект-значение: сохранённые цена и права тарифа на момент изменения; после создания не меняется. Хранится в таблице plan_versions. Ограниченный контекст — «Тарифы и оплата».

Атрибуты:

- `+версия: int {readOnly}` — Порядковый номер версии тарифа. Тип int — целое число (счётчик, номер или размер). Открытый только для чтения ({readOnly}): объект-значение не меняется после создания.
- `+цена: Деньги {readOnly}` — Цена в этой версии. Тип Деньги — объект класса «Деньги». Открытый только для чтения ({readOnly}): объект-значение не меняется после создания.
- `+права: ПраваТарифа {readOnly}` — Права тарифа в этой версии. Тип ПраваТарифа — объект класса «ПраваТарифа». Открытый только для чтения ({readOnly}): объект-значение не меняется после создания.
- `+действуетС: datetime {readOnly}` — С какого момента действует версия: лимиты — для новых задач, цена — с нового периода. Тип datetime — дата и время в UTC (момент события). Открытый только для чтения ({readOnly}): объект-значение не меняется после создания.
- `+изменил: UUID {readOnly}` — Идентификатор владельца, внёсшего изменение (ссылка на другой агрегат — по идентификатору). Тип UUID — UUID (уникальный идентификатор, который нельзя подобрать перебором). Открытый только для чтения ({readOnly}): объект-значение не меняется после создания.

Операции:

- `+Применима(дата: datetime): bool` — Действовала ли версия на указанную дату (для финансового отчёта). Параметры: дата — дата и время в UTC (момент события); результат bool — логическое значение «да/нет».

#### ПраваТарифа (класс-сущность)

Объект-значение: набор прав тарифа с типизированными полями вместо словаря; недопустимые значения отклоняются при создании. Решение «допустимы ли параметры генерации на тарифе» принимается только здесь. Ограниченный контекст — «Тарифы и оплата».

## Отношения

- **Ассоциация Подписка — Пользователь «оформлена»**. Ассоциация по внешнему ключу subscriptions.user_id: подписка зависит от пользователя (навигация от подписки к пользователю); у пользователя может быть несколько подписок во времени — кратность 0..* к 1. Реализуется атрибутом идПользователя — агрегаты ссылаются друг на друга только по идентификатору. Кратности: Подписка — 0..*, Пользователь — 1. Имя ассоциации «оформлена» — глагольная фраза, читается от Подписка к Пользователь.
- **Ассоциация Подписка — Тариф «по тарифу»**. Ассоциация по внешнему ключу subscriptions.plan_code: подписка ссылается на тариф; тариф существует независимо от подписок. Реализуется атрибутом кодТарифа — агрегаты ссылаются друг на друга только по идентификатору. Кратности: Подписка — 0..*, Тариф — 1. Имя ассоциации «по тарифу» — глагольная фраза, читается от Подписка к Тариф.
- **Ассоциация Платёж — Подписка «оплачивает»**. Ассоциация по внешнему ключу payments.subscription_id: платёж относится к подписке; на одну подписку может прийтись несколько платежей (продления, повторные попытки). Реализуется атрибутом идПодписки — агрегаты ссылаются друг на друга только по идентификатору. Кратности: Платёж — 0..*, Подписка — 1. Имя ассоциации «оплачивает» — глагольная фраза, читается от Платёж к Подписка.
- **Ассоциация СуточныйСчётчик — Пользователь «учитывает»**. Ассоциация по внешнему ключу usage_daily.user_id: суточный счётчик принадлежит пользователю, по одному на каждые сутки работы. Реализуется атрибутом идПользователя — агрегаты ссылаются друг на друга только по идентификатору. Кратности: СуточныйСчётчик — 0..*, Пользователь — 1. Имя ассоциации «учитывает» — глагольная фраза, читается от СуточныйСчётчик к Пользователь.
- **Ассоциация ЗаписьАудита — Пользователь «сделана»**. Ассоциация по внешнему ключу audit_log.actor_id: запись журнала ссылается на сотрудника. Не композиция: журнал хранится и после блокировки сотрудника. Реализуется атрибутом идСотрудника — агрегаты ссылаются друг на друга только по идентификатору. Кратности: ЗаписьАудита — 0..*, Пользователь — 1. Имя ассоциации «сделана» — глагольная фраза, читается от ЗаписьАудита к Пользователь.
- **Композиция Тариф — ВерсияТарифа**. Композиция (атрибут версии): версии тарифа — часть агрегата «Тариф» и вне его не имеют смысла; создаёт их только корень, при удалении тарифа удаляются и версии. Кратности: Тариф — 1, ВерсияТарифа — 1..*.
- **Композиция Тариф — ПраваТарифа**. Композиция (атрибут права): действующие права — объект-значение внутри тарифа, при изменении условий заменяется целиком. Кратности: Тариф — 1, ПраваТарифа — 1.
- **Композиция ВерсияТарифа — ПраваТарифа**. Композиция (атрибут права): права, сохранённые в версии тарифа; существуют, пока существует версия. Кратности: ВерсияТарифа — 1, ПраваТарифа — 1.
- **Ассоциация Материал — Пользователь «принадлежит»**. Ассоциация по внешнему ключу materials.user_id: материал принадлежит пользователю; навигация от материала к владельцу (проверка прав). Реализуется атрибутом идПользователя — агрегаты ссылаются друг на друга только по идентификатору. Кратности: Материал — 0..*, Пользователь — 1. Имя ассоциации «принадлежит» — глагольная фраза, читается от Материал к Пользователь.
- **Ассоциация Материал — ВерсияМодели «создан версией»**. Ассоциация: материал создан определённой версией весов LoRA; версия входит в хэш параметров кэша. Реализуется атрибутом идВерсииМодели — агрегаты ссылаются друг на друга только по идентификатору. Кратности: Материал — 0..*, ВерсияМодели — 1. Имя ассоциации «создан версией» — глагольная фраза, читается от Материал к ВерсияМодели.
- **Композиция Материал — ПараметрыГенерации**. Композиция (атрибут параметры): параметры генерации хранятся в самом материале (поле params) и удаляются вместе с ним. Кратности: Материал — 1, ПараметрыГенерации — 1.
- **Композиция ПараметрыГенерации — ПараметрыШума**. Композиция (атрибут шум): параметры шума — часть параметров генерации. Кратности: ПараметрыГенерации — 1, ПараметрыШума — 1.
- **Композиция Пресет — ПараметрыШума**. Композиция (атрибут шум): параметры шума пресета хранятся в пресете (поле noise) и удаляются вместе с ним. Кратности: Пресет — 1, ПараметрыШума — 1.
- **Композиция Материал — Этап**. Композиция (атрибут этапы): записи этапов — часть агрегата «Материал», добавляются через корень и удаляются вместе с ним при истечении срока хранения. Кратности: Материал — 1, Этап — 0..*.
- **Композиция Материал — КартаМатериала**. Композиция (атрибут карты): карты — часть агрегата «Материал»; при удалении материала файлы удаляются из хранилища. Кратности: Материал — 1, КартаМатериала — 0..*.
- **Зависимость «call» ОкноВхода → КонтроллерВхода**. Окно входа вызывает операции контроллера входа: Войти(), Зарегистрировать(), ЗапроситьВосстановление().
- **Зависимость «instantiate» КонтроллерВхода → Пользователь**. Операция Зарегистрировать() контроллера создаёт объект «Пользователь» (новую учётную запись); остальные операции вызывают его операции-переходы.
- **Зависимость «call» КонтроллерВхода → ШлюзПочты**. Контроллер входа вызывает Отправить() шлюза почты для писем подтверждения адреса и сброса пароля.
- **Зависимость «call» ГлавноеОкно → ПроверкаДоступа**. Главное окно вызывает ЗавершитьСеанс() при выходе.
- **Зависимость «use» ПроверкаДоступа → Пользователь**. Проверка доступа читает статус, роль и версию токенов пользователя при каждом запросе.
- **Зависимость «create» ОкноВхода → ГлавноеОкно**. После успешного входа окно входа создаёт главное окно.
- **Зависимость «call» ОкноГенератора → КонтроллерГенерации**. Окно генератора вызывает СоздатьМатериал(), ОтменитьЗадачу(), ПолучитьПревью().
- **Зависимость «call» ОкноГенератора → АссистентПромптов**. Окно генератора запрашивает подсказки у ассистента после паузы в наборе (премиум).
- **Композиция ОкноГенератора — ПараметрыГенерации**. Композиция: окно владеет текущими параметрами (атрибут параметры); при закрытии окна они удаляются, в материал передаётся тот же неизменяемый объект. Кратности: ОкноГенератора — 1, ПараметрыГенерации — 1.
- **Зависимость «call» КонтроллерГенерации → ПроверкаПравТарифа**. Контроллер генерации вызывает НайтиНарушения(), затем ЗарезервироватьГенерацию() перед созданием задачи.
