# СЦ5. Сценарий взаимодействия Почтового сервиса с системой

| Поле | Содержание |
|---|---|
| Название | Сценарий доставки писем почтовым сервисом |
| Действующие лица | Почтовый сервис |
| Краткое описание | Почтовый сервис принимает от системы письма (подтверждение адреса, сброс пароля) и доставляет их пользователю. |
| Предусловия | Система сформировала письмо в прецеденте «Регистрация и вход в систему». |
| Постусловия | Письмо доставлено пользователю либо система получила сообщение о невозможности доставки. |
| Основной поток | 1. Почтовый сервис получает от системы письмо: адрес, тема, текст со ссылкой.<br>2. Почтовый сервис доставляет письмо на адрес пользователя (E1).<br>3. Почтовый сервис сообщает системе о приёме письма к доставке.<br>4. Выполнение сценария завершается. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [Адрес не существует или ящик недоступен]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Почтовый сервис сообщает системе о недоставке; система помечает адрес как неподтверждённый.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 4. |
| Подпотоки | Подпотоков нет. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
