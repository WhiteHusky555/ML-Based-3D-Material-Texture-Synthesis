# UC2. Описание прецедента «Генерация материала»

| Поле | Содержание |
|---|---|
| Название | S2. Реализация прецедента «Генерация материала» |
| Действующие лица | Пользователь (Премиум-пользователь) |
| Краткое описание | Пользователь задаёт форму материала процедурным шумом и описание; система проверяет права тарифа, генерирует текстуру диффузионной моделью, повышает разрешение и рассчитывает PBR-карты. Обработка асинхронная, ход выполнения отображается. |
| Предусловия | Пользователь вошёл в систему и выбрал действие «Генерация материала». |
| Постусловия | Материал (набор карт) сохранён в истории со сроком хранения по тарифу либо генерация отменена. |
| Основной поток | 1. Система отображает окно генератора: пресеты, модификаторы, поле описания, превью шума плиткой 3×3, кнопка «Сгенерировать».<br>2. S1 // Задание формы материала<br>3. S2 // Формирование промпта (точка расширения «Ввод описания»)<br>4. Пользователь нажимает «Сгенерировать».<br>5. S3 // Проверка прав тарифа (E1, E3)<br>6. A1. [Параметры совпадают с ранее созданным материалом] (точка расширения «Запуск генерации»)<br>7. Система ставит задачу в очередь и отображает ход выполнения (точка расширения «Ожидание результата», A2).<br>8. S4 // Генерация текстуры (E2)<br>9. S5 // Повышение разрешения текстуры<br>10. S6 // Расчёт PBR-карт<br>11. Система сохраняет материал в истории и открывает его в 3D-просмотре.<br>12. Выполнение прецедента завершается. |
| Альтернативные потоки | A1. [Параметры совпадают с ранее созданным материалом] — «Выдача готового материала из кэша»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система выдаёт готовый материал без повторной генерации; квота не списывается.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 11 основного потока.<br>A2. [Нажата «Отменить» во время ожидания] — «Отмена генерации»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система прерывает задачу между шагами генерации; квота не списывается.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 основного потока. |
| Потоки ошибок | E1. [Суточная квота исчерпана]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает о лимите и предлагает премиум-тариф.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 основного потока.<br>E2. [Сбой генерации]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система повторяет задачу до 3 раз; при неудаче сообщает об ошибке, квота не списывается.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 основного потока.<br>E3. [Выбранные параметры недоступны на тарифе пользователя]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система помечает параметры «доступно в Премиум».<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 основного потока.<br>E4. [Языковая модель недоступна]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Подсказка не показывается.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 4 подпотока S2.<br>E5. [Файл референса неподходящего типа или больше 10 МБ]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает о требованиях к файлу.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 подпотока S8. |
| Подпотоки | S1. «Задание формы материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Пользователь выбирает пресет материала или (в расширенном режиме) тип шума, масштаб, октавы, растяжение, seed.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система показывает бесшовное превью шума плиткой 3×3.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. Пункты 1–2 повторяются, пока форма не устроит пользователя.<br>S2. «Формирование промпта»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Пользователь вводит описание материала (необязательно) и отмечает модификаторы.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. S7 [Тариф «Премиум» и пауза в наборе описания] // Получение подсказок к промпту<br>&nbsp;&nbsp;&nbsp;&nbsp;3. S8 [Тариф «Премиум» и загружена картинка-референс] // Учёт картинки-референса<br>&nbsp;&nbsp;&nbsp;&nbsp;4. Система собирает промпт по шаблону (обязательные слова, триггер LoRA, negative prompt) и проверяет длину — не больше 77 токенов CLIP.<br>S3. «Проверка прав тарифа»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система проверяет суточную квоту пользователя (E1).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система проверяет допустимость разрешения, числа шагов, вариантов и референса для тарифа (E3).<br>S4. «Генерация текстуры»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система строит бесшовную карту шума 512².<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Модель SD 1.5 + ControlNet + LoRA генерирует цветовую текстуру 512²: бесплатный тариф — 20 шагов, 1 вариант; премиум — 30–40 шагов, до 4 вариантов.<br>S5. «Повышение разрешения текстуры»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система бесшовно увеличивает текстуру до 1024² (бесплатный тариф) или 2048²/4096² (премиум).<br>S6. «Расчёт PBR-карт»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система рассчитывает карты высот, нормалей, шероховатости и затенения с заворачиванием краёв.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система сохраняет карты в хранилище.<br>S7. [Тариф «Премиум» и пауза в наборе описания] — «Получение подсказок к промпту»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система передаёт описание и текущие параметры языковой модели.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система показывает всплывающую подсказку с 1–3 вариантами улучшения (E4).<br>&nbsp;&nbsp;&nbsp;&nbsp;3. Пользователь применяет вариант или закрывает подсказку.<br>S8. [Тариф «Премиум» и загружена картинка-референс] — «Учёт картинки-референса»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Пользователь загружает картинку JPEG, PNG или WebP (E5).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Пользователь задаёт силу влияния референса. |
| Приоритет (Критично | Важно | Желательно) | Критично |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Всегда |
