# UC11. Описание прецедента «Работа со ссылкой на цепочку»

| Поле | Содержание |
|---|---|
| Название | Реализация прецедента «Работа со ссылкой на цепочку» (вызывается из S5, пункт 6 потока UC5) |
| Действующие лица | Пользователь |
| Краткое описание | Пользователь передаёт цепочку запросов другому человеку: публикует снимок цепочки по ссылке и пересылает ссылку гостю либо отзывает ссылку. |
| Предусловия | Пользователь вошёл в систему, открыл историю запросов и нажал «Поделиться» у цепочки. |
| Постусловия | Ссылка создана (или снимок обновлён по прежнему адресу) и показана пользователю либо ссылка отозвана. |
| Основной поток | 1. Система показывает окно публикации: предупреждение, что ссылку может открыть любой, у кого она есть, и кнопки «Создать ссылку», «Закрыть доступ» (если ссылка действует) и «Отмена».<br>2. Пользователь выбирает действие (точка расширения «Выбор действия»).<br>3. S1 [Нажата «Создать ссылку»] // Публикация цепочки по ссылке<br>4. S2 [Нажата «Закрыть доступ», ссылка действует] // Отзыв ссылки на цепочку<br>5. A1. [Нажата «Отмена»]<br>6. Выполнение прецедента завершается. |
| Альтернативные потоки | A1. [Нажата «Отмена»]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система закрывает окно публикации без изменений.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение прецедента завершается. |
| Потоки ошибок | Потоки не определены. |
| Подпотоки | S1. «Публикация цепочки по ссылке»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система создаёт снимок цепочки без личных данных (или обновляет снимок по тому же адресу) и показывает ссылку с кнопкой «Копировать».<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Пользователь копирует ссылку и сам пересылает её гостю; гость открывает её в прецеденте «Просмотр опубликованной цепочки» (UC10).<br>S2. «Отзыв ссылки на цепочку»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система отключает ссылку: снимок по ней больше не открывается.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Копии цепочки, уже сделанные другими пользователями, остаются у них. |
| Приоритет (Критично | Важно | Желательно) | Желательно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Иногда |
