# СЦ6. Сценарий использования системы Аналитиком

| Поле | Содержание |
|---|---|
| Название | Сценарий анализа показателей системы аналитиком |
| Действующие лица | Аналитик (работник системы) |
| Краткое описание | Аналитик получает агрегированные обезличенные показатели работы сервиса и выгружает отчёты. Доступ только на чтение: данные системы аналитик не изменяет, персональные данные пользователей ему не показываются. |
| Предусловия | Владелец назначил учётной записи роль «аналитик»; аналитик выполнил вход в систему. |
| Постусловия | Аналитик получил отчёты за выбранные периоды и вышел из системы; данные системы не изменены. |
| Основной поток | 1. Система проверяет роль учётной записи (E1).<br>2. Система отображает панель аналитика с возможными действиями:<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Анализ показателей системы<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Выход из системы<br>3. Аналитик выбирает действие.<br>4. S1. [Выбран Анализ показателей системы]<br>5. S2. [Выбран Выход из системы]<br>6. Переход к пункту 2. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [У учётной записи нет роли «аналитик» или «владелец»]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система не показывает панель и сообщает об отсутствии прав; выполнение сценария завершается.<br>E2. [Владелец отозвал роль во время сеанса]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система отклоняет очередной запрос и завершает сеанс; выполнение сценария завершается. |
| Подпотоки | Подпоток S1 — реализация прецедента UC8, описан отдельной таблицей.<br>S2. [Выбран Выход из системы]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система аннулирует токены сеанса.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение сценария завершается. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
