# СЦ3. Сценарий использования системы Администратором

| Поле | Содержание |
|---|---|
| Название | Сценарий обслуживания системы администратором |
| Действующие лица | Администратор (работник системы) |
| Краткое описание | Администратор выполняет техническое обслуживание системы: ведёт учётные записи пользователей, пресеты материалов и версии моделей, следит за работой сервисов. Цены и лимиты тарифов и роли сотрудников ему недоступны. |
| Предусловия | Владелец назначил учётной записи роль «администратор»; администратор выполнил вход в систему. |
| Постусловия | Изменения сохранены в базе и записаны в журнал аудита; администратор вышел из системы. |
| Основной поток | 1. Система проверяет роль учётной записи (E1).<br>2. Система отображает панель администратора с возможными действиями:<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Администрирование системы<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Выход из системы<br>3. Администратор выбирает действие.<br>4. S1. [Выбрано Администрирование системы]<br>5. S2. [Выбран Выход из системы]<br>6. Переход к пункту 2. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [У учётной записи нет роли «администратор»]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система не показывает панель и сообщает об отсутствии прав; выполнение сценария завершается.<br>E2. [Владелец отозвал роль во время сеанса]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система отклоняет очередной запрос и завершает сеанс; выполнение сценария завершается. |
| Подпотоки | Подпоток S1 — реализация прецедента UC7, описан отдельной таблицей.<br>S2. [Выбран Выход из системы]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система аннулирует токены сеанса.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение сценария завершается. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
