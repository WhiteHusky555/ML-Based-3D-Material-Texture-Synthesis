# UC7. Описание прецедента «Администрирование системы»

| Поле | Содержание |
|---|---|
| Название | S1. Реализация прецедента «Администрирование системы» |
| Действующие лица | Администратор |
| Краткое описание | Администратор выбирает раздел панели и выполняет операцию обслуживания: ведение учётных записей пользователей, пресетов материалов, версий модели или технический мониторинг. Каждое изменение записывается в журнал аудита. |
| Предусловия | Администратор вошёл в систему; учётная запись имеет роль «администратор». |
| Постусловия | Изменения сохранены и записаны в журнал аудита либо администратор получил технические показатели. |
| Основной поток | 1. Система отображает панель администрирования с разделами: Пользователи, Пресеты, Модели, Мониторинг.<br>2. Администратор выбирает раздел (точка расширения «Выбор раздела»).<br>3. S1 [Выбран раздел «Пользователи»] // Управление учётными записями пользователей<br>4. S2 [Выбран раздел «Пресеты»] // Ведение пресетов материалов<br>5. S3 [Выбран раздел «Модели»] // Обновление версии модели<br>6. S4 [Выбран раздел «Мониторинг»] // Технический мониторинг<br>7. Пункты 1–6 повторяются, пока администратор не закроет панель.<br>8. Выполнение прецедента завершается. |
| Альтернативные потоки | A1. [Выбрано ручное назначение тарифа]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Администратор выбирает тариф, срок его действия и указывает причину (компенсация, тестирование).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 4 подпотока S1. |
| Потоки ошибок | E1. [Попытка заблокировать учётную запись сотрудника или собственную]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система запрещает действие: роли и учётные записи сотрудников ведёт владелец.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 подпотока S1.<br>E2. [Параметры пресета вне допустимых диапазонов]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает допустимые значения.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 подпотока S2.<br>E3. [Файл весов не в формате safetensors или несовместим с базовой моделью]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система отклоняет файл и сообщает причину.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 подпотока S3.<br>E4. [Сервис метрик недоступен]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает последние сохранённые значения с отметкой времени. |
| Подпотоки | S1. «Управление учётными записями пользователей»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Администратор находит пользователя по e-mail.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система показывает тариф, остаток квоты, историю подписки и статус учётной записи.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. Администратор блокирует или разблокирует учётную запись (E1) либо назначает тариф вручную (A1).<br>&nbsp;&nbsp;&nbsp;&nbsp;4. Система сохраняет изменение; при блокировке сразу аннулирует сеансы пользователя.<br>&nbsp;&nbsp;&nbsp;&nbsp;5. S5 // Запись в журнал аудита<br>S2. «Ведение пресетов материалов»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Администратор создаёт или изменяет пресет: параметры шума, шаблон промпта, базовую шероховатость, миниатюру; при необходимости скрывает устаревший пресет.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система проверяет параметры (E2) и сохраняет пресет.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. S5 // Запись в журнал аудита<br>S3. «Обновление версии модели»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Администратор загружает файл весов LoRA в формате safetensors (E3).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система проверяет совместимость с базовой моделью SD 1.5 (E3) и строит пробную текстуру.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. Администратор подтверждает переключение; система переводит генерацию на новую версию, кэш результатов старой версии больше не используется.<br>&nbsp;&nbsp;&nbsp;&nbsp;4. S5 // Запись в журнал аудита<br>S4. «Технический мониторинг»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает длину очередей, загрузку видеокарт, время этапов генерации, долю ошибок и состояние сервисов за выбранный период (E4).<br>S5. «Запись в журнал аудита»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сохраняет запись: сотрудник, время, действие, объект, старое и новое значение. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
