# UC4. Описание прецедента «Экспорт материала»

| Поле | Содержание |
|---|---|
| Название | S4. Реализация прецедента «Экспорт материала» |
| Действующие лица | Пользователь (Премиум-пользователь) |
| Краткое описание | Пользователь получает архив ZIP с картами материала, упакованными под выбранный движок. |
| Предусловия | Материал создан и не удалён по сроку хранения. |
| Постусловия | Архив материала скачан пользователем. |
| Основной поток | 1. S1 // Выбор целевого движка<br>2. S2 // Упаковка карт под движок (точка расширения «Подготовка карт»)<br>3. S3 [Выбран Unreal Engine] // Перевод карты нормалей в формат DirectX<br>4. S4 [Тариф «Премиум», выбраны 16 бит / EXR / glb] // Экспорт в расширенных форматах<br>5. S5 // Формирование архива материала (E1)<br>6. Браузер скачивает архив по выданной ссылке.<br>7. Выполнение прецедента завершается. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [Файлы материала удалены по истечении срока хранения]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает, что материал недоступен, и предлагает создать его заново по сохранённым параметрам.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение прецедента завершается. |
| Подпотоки | S1. «Выбор целевого движка»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Пользователь выбирает Blender, Unity или Unreal Engine.<br>S2. «Упаковка карт под движок»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система упаковывает каналы и именует файлы по соглашениям движка: Blender — отдельные карты; Unity — Metallic/Smoothness; Unreal Engine — ORM.<br>S3. «Перевод карты нормалей в формат DirectX»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система инвертирует зелёный канал карты нормалей.<br>S4. «Экспорт в расширенных форматах»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система добавляет карту высот в 16 бит, файлы EXR и модель .glb со сферой предпросмотра.<br>S5. «Формирование архива материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система собирает ZIP с картами и файлом manifest.json с параметрами материала.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система выдаёт временную ссылку на скачивание. |
| Приоритет (Критично | Важно | Желательно) | Критично |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
