# СЦ8. Сценарий использования системы Гостем

| Поле | Содержание |
|---|---|
| Название | Сценарий просмотра опубликованной цепочки гостем |
| Действующие лица | Гость |
| Краткое описание | Гость открывает ссылку на опубликованную цепочку запросов, которую ему прислал пользователь, просматривает снимок и при наличии учётной записи продолжает цепочку у себя. |
| Предусловия | Пользователь опубликовал цепочку и передал ссылку гостю. |
| Постусловия | Гость закрыл страницу либо в его аккаунте создана копия цепочки. |
| Основной поток | 1. Гость открывает ссылку в браузере.<br>2. S1 // Просмотр опубликованной цепочки (A1, E1)<br>3. Выполнение сценария завершается. |
| Альтернативные потоки | A1. [Нажата «Продолжить у себя», вход не выполнен]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Выполняется прецедент «Регистрация и вход в систему» (UC1).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система создаёт копию цепочки в аккаунте и открывает её в генераторе.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. Дальнейшая работа — по сценарию пользователя СЦ1. |
| Потоки ошибок | E1. [Ссылка отозвана или не существует]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает, что ссылка недоступна, и предлагает перейти на главную страницу.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение сценария завершается. |
| Подпотоки | Подпоток S1 — реализация прецедента UC10, описан отдельной таблицей. |
| Приоритет (Критично | Важно | Желательно) | Желательно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Иногда |
