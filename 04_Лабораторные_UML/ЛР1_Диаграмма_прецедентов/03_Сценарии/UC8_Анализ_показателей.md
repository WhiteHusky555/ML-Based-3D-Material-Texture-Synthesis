# UC8. Описание прецедента «Анализ показателей системы»

| Поле | Содержание |
|---|---|
| Название | S1 (СЦ6), S2 (СЦ7). Реализация прецедента «Анализ показателей системы» |
| Действующие лица | Аналитик, Владелец |
| Краткое описание | Сотрудник выбирает период и отчёт; система рассчитывает агрегированные обезличенные показатели и показывает их графиками и таблицами; отчёт можно выгрузить в CSV. |
| Предусловия | Сотрудник вошёл в систему; учётная запись имеет роль «аналитик» или «владелец». |
| Постусловия | Сотрудник получил показатели за выбранный период, при выгрузке — файл CSV; данные системы не изменены. |
| Основной поток | 1. Система отображает панель аналитики: список отчётов, период по умолчанию — последние 30 дней.<br>2. S1 // Выбор периода и фильтров<br>3. Сотрудник выбирает отчёт (точка расширения «Выбор отчёта»).<br>4. S2 // Расчёт агрегированных показателей (A1, E1)<br>5. S3 [Выбран отчёт «Использование»] // Отчёт об использовании сервиса<br>6. S4 [Выбран отчёт «Конверсия»] // Отчёт о конверсии в премиум<br>7. S5 [Выбран отчёт «Генерации»] // Отчёт о генерациях<br>8. Сотрудник просматривает результат (точка расширения «Просмотр результата»).<br>9. S6 [Нажата «Выгрузить CSV»] // Выгрузка отчёта в CSV<br>10. Пункты 2–9 повторяются, пока сотрудник не закроет панель.<br>11. Выполнение прецедента завершается. |
| Альтернативные потоки | A1. [За выбранный период нет данных]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает, что данных нет, и предлагает расширить период.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 2 основного потока. |
| Потоки ошибок | E1. [Расчёт не уложился в 30 секунд]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система ставит расчёт в фоновую очередь и уведомляет сотрудника, когда отчёт готов.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 8 основного потока. |
| Подпотоки | S1. «Выбор периода и фильтров»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Сотрудник задаёт период и при необходимости фильтры: тариф, пресет.<br>S2. «Расчёт агрегированных показателей»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система рассчитывает показатели по обезличенным данным: e-mail и другие персональные данные в отчёт не попадают.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Группы меньше 5 пользователей система объединяет в строку «прочие».<br>S3. «Отчёт об использовании сервиса»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает регистрации, активных пользователей за день и месяц, удержание по неделям и число генераций по тарифам.<br>S4. «Отчёт о конверсии в премиум»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает долю пользователей, оформивших премиум, отказы от подписки и переходы к тарифам после исчерпания квоты.<br>S5. «Отчёт о генерациях»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает популярность пресетов, среднее время этапов, долю выдач из кэша, долю отмен и ошибок, использование подсказок и референсов.<br>S6. «Выгрузка отчёта в CSV»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система формирует файл CSV с показателями отчёта и выдаёт временную ссылку на скачивание. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
