# UC3. Описание прецедента «Просмотр материала в 3D»

| Поле | Содержание |
|---|---|
| Название | S3. Реализация прецедента «Просмотр материала в 3D» |
| Действующие лица | Пользователь (Премиум-пользователь) |
| Краткое описание | Пользователь рассматривает готовый материал на 3D-объекте с освещением, переключает карты и форму объекта; премиум-пользователь — на своей 3D-модели. |
| Предусловия | Материал создан и не удалён по сроку хранения. |
| Постусловия | Пользователь закрыл 3D-просмотр. |
| Основной поток | 1. S1 // Загрузка карт материала<br>2. Система показывает материал на сфере с освещением.<br>3. Пользователь вращает и масштабирует объект.<br>4. Пользователь выбирает режим просмотра (точка расширения «Выбор режима»).<br>5. S2 [Выбрана вкладка карты] // Переключение отображаемой карты<br>6. S3 [Выбрана сфера, плоскость или куб] // Смена формы объекта<br>7. S4 [Тариф «Премиум» и загружена модель] // Просмотр на своей 3D-модели<br>8. Пункты 3–7 повторяются, пока пользователь не закроет просмотр.<br>9. Выполнение прецедента завершается. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [Файл модели не поддерживается или превышает лимит]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает о поддерживаемых форматах (GLB, OBJ, FBX) и лимите размера.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 2 основного потока. |
| Подпотоки | S1. «Загрузка карт материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система загружает карты материала из хранилища по временным ссылкам.<br>S2. «Переключение отображаемой карты»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает на объекте выбранную карту: albedo, normal, height, roughness или AO.<br>S3. «Смена формы объекта»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система заменяет объект; на плоскости материал повторяется 3×3 для проверки шва.<br>S4. «Просмотр на своей 3D-модели»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Пользователь загружает модель (E1).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система накладывает материал на модель (по развёртке или трипланарной проекцией). |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
