# СЦ7. Сценарий использования системы Владельцем

| Поле | Содержание |
|---|---|
| Название | Сценарий управления сервисом владельцем |
| Действующие лица | Владелец (работник системы) |
| Краткое описание | Владелец управляет коммерческой стороной сервиса: ценами и лимитами тарифов, ролями сотрудников, финансовой отчётностью; пользуется также анализом показателей. |
| Предусловия | Учётная запись владельца создана при развёртывании системы; владелец выполнил вход. |
| Постусловия | Изменения тарифов и ролей сохранены и записаны в журнал аудита либо владелец получил отчёты; владелец вышел из системы. |
| Основной поток | 1. Система проверяет роль учётной записи (E1).<br>2. Система отображает панель владельца с возможными действиями:<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Управление тарифами и персоналом<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Анализ показателей системы<br>&nbsp;&nbsp;&nbsp;&nbsp;✓ Выход из системы<br>3. Владелец выбирает действие.<br>4. S1. [Выбрано Управление тарифами и персоналом]<br>5. S2. [Выбран Анализ показателей системы]<br>6. S3. [Выбран Выход из системы]<br>7. Переход к пункту 2. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [У учётной записи нет роли «владелец»]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система не показывает панель и сообщает об отсутствии прав; выполнение сценария завершается. |
| Подпотоки | Подпотоки S1 и S2 — реализации прецедентов UC9 и UC8, описаны отдельными таблицами.<br>S3. [Выбран Выход из системы]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система аннулирует токены сеанса.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение сценария завершается. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Иногда |
