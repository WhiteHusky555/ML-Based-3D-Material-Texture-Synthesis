# UC5. Описание прецедента «Работа с историей запросов»

| Поле | Содержание |
|---|---|
| Название | S5. Реализация прецедента «Работа с историей запросов» |
| Действующие лица | Пользователь |
| Краткое описание | Пользователь просматривает цепочки запросов, открывает материалы, удаляет цепочки и материалы, создаёт варианты, публикует цепочку по ссылке и отзывает ссылку. |
| Предусловия | Пользователь вошёл в систему и выбрал «Работа с историей запросов». |
| Постусловия | Выбранное действие выполнено; история обновлена. |
| Основной поток | 1. S1 // Просмотр списка цепочек (A1)<br>2. Пользователь выбирает действие (точка расширения «Выбор действия»).<br>3. S2 [Выбран запрос в цепочке] // Открытие материала<br>4. S3 [Нажата «Удалить», удаление подтверждено] // Удаление цепочки или материала<br>5. S4 [Нажата «Изменить параметры»] // Создание варианта материала<br>6. S5 [Нажата «Поделиться»] // Публикация цепочки по ссылке<br>7. S6 [Нажата «Закрыть доступ», ссылка действует] // Отзыв ссылки на цепочку<br>8. Переход к пункту 1. |
| Альтернативные потоки | A1. [История пуста]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система предлагает создать первый материал.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение прецедента завершается. |
| Потоки ошибок | Потоки не определены. |
| Подпотоки | S1. «Просмотр списка цепочек»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает цепочки пользователя: название, дату, миниатюру последнего результата, признак публикации.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. В открытой цепочке система показывает запросы по порядку с номерами, кодами, миниатюрами и сроками хранения.<br>S2. «Открытие материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система открывает материал выбранного запроса в генераторе и 3D-просмотре; цепочку можно продолжить уточнением (прецедент «Генерация материала»).<br>S3. «Удаление цепочки или материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система удаляет выбранный материал и его файлы либо всю цепочку с её запросами; ссылка на удалённую цепочку отзывается.<br>S4. «Создание варианта материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система копирует параметры материала в генератор.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполняется прецедент «Генерация материала» с этими параметрами.<br>S5. «Публикация цепочки по ссылке»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система предупреждает, что ссылку может открыть любой, у кого она есть.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Пользователь подтверждает публикацию.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. Система создаёт снимок цепочки без личных данных (или обновляет снимок по тому же адресу) и показывает ссылку с кнопкой «Копировать».<br>S6. «Отзыв ссылки на цепочку»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система отключает ссылку: снимок по ней больше не открывается.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Копии цепочки, уже сделанные другими пользователями, остаются у них. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
