# UC5. Описание прецедента «Работа с историей материалов»

| Поле | Содержание |
|---|---|
| Название | S5. Реализация прецедента «Работа с историей материалов» |
| Действующие лица | Пользователь |
| Краткое описание | Пользователь просматривает созданные материалы, открывает, удаляет их или создаёт вариант с изменёнными параметрами. |
| Предусловия | Пользователь вошёл в систему и выбрал «Работа с историей материалов». |
| Постусловия | Выбранное действие выполнено; история обновлена. |
| Основной поток | 1. S1 // Просмотр списка материалов (A1)<br>2. Пользователь выбирает действие с материалом (точка расширения «Выбор действия»).<br>3. S2 [Выбран материал в списке] // Открытие материала<br>4. S3 [Нажата «Удалить», удаление подтверждено] // Удаление материала<br>5. S4 [Нажата «Изменить параметры»] // Создание варианта материала<br>6. Переход к пункту 1. |
| Альтернативные потоки | A1. [История пуста]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система предлагает создать первый материал.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение прецедента завершается. |
| Потоки ошибок | Потоки не определены. |
| Подпотоки | S1. «Просмотр списка материалов»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает материалы пользователя с миниатюрами, датой создания и сроком хранения.<br>S2. «Открытие материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система открывает материал в генераторе и 3D-просмотре.<br>S3. «Удаление материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система удаляет материал и его файлы из хранилища.<br>S4. «Создание варианта материала»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система копирует параметры материала в генератор.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполняется прецедент «Генерация материала» с этими параметрами. |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
