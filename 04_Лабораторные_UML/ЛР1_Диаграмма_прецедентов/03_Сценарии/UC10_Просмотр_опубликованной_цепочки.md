# UC10. Описание прецедента «Просмотр опубликованной цепочки»

| Поле | Содержание |
|---|---|
| Название | S1 (СЦ8). Реализация прецедента «Просмотр опубликованной цепочки» |
| Действующие лица | Гость (Пользователь) |
| Краткое описание | Гость просматривает снимок опубликованной цепочки: описания, параметры, превью и 3D-просмотр без скачивания; пользователь с учётной записью продолжает цепочку у себя. |
| Предусловия | Открыта ссылка на опубликованную цепочку. |
| Постусловия | Гость закрыл страницу либо в аккаунте пользователя создана копия цепочки. |
| Основной поток | 1. S1 // Загрузка снимка цепочки (E1)<br>2. Система показывает название цепочки и её шаги по порядку — описание, параметры, превью — и кнопку «Продолжить у себя».<br>3. Гость выбирает действие (точка расширения «Выбор действия»).<br>4. S2 [Выбран шаг с готовым материалом] // Просмотр материала цепочки в 3D<br>5. A1. [Нажата «Продолжить у себя», вход не выполнен]<br>6. S3 [Нажата «Продолжить у себя», вход выполнен] // Продолжение цепочки у себя<br>7. Пункты 3–6 повторяются, пока гость не закроет страницу.<br>8. Выполнение прецедента завершается. |
| Альтернативные потоки | A1. [Нажата «Продолжить у себя», вход не выполнен]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система открывает окно входа — выполняется прецедент «Регистрация и вход в систему» (UC1).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 6 основного потока. |
| Потоки ошибок | E1. [Ссылка отозвана или не существует]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает, что ссылка недоступна.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Выполнение прецедента завершается.<br>E2. [Файлы материала удалены по сроку хранения]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Вместо 3D-просмотра система показывает «файлы удалены»; параметры шага остаются видны.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 3 основного потока. |
| Подпотоки | S1. «Загрузка снимка цепочки»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система проверяет ссылку: она существует и не отозвана (E1).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система загружает снимок: название, описания, параметры, превью; имя и e-mail автора не показываются.<br>S2. «Просмотр материала цепочки в 3D»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система загружает карты уменьшенного разрешения по временным ссылкам (E2).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Гость вращает объект и переключает карты; скачивания нет.<br>S3. «Продолжение цепочки у себя»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система создаёт в аккаунте пользователя копию цепочки: шаги снимка переносятся предысторией с миниатюрами; номера запросов и квота не тратятся.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система открывает копию в генераторе; уточнения — собственные запросы пользователя по его тарифу (прецедент «Генерация материала»). |
| Приоритет (Критично | Важно | Желательно) | Желательно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Иногда |
