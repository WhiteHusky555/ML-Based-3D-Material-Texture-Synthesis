# UC6. Описание прецедента «Управление подпиской»

| Поле | Содержание |
|---|---|
| Название | S6. Реализация прецедента «Управление подпиской» |
| Действующие лица | Пользователь, Платёжная система |
| Краткое описание | Пользователь просматривает тарифы, оформляет премиум-подписку с оплатой через платёжную систему или отменяет подписку. |
| Предусловия | Пользователь вошёл в систему и выбрал «Управление подпиской». |
| Постусловия | Тариф пользователя изменён или оставлен прежним; сроки хранения материалов пересчитаны. |
| Основной поток | 1. S1 // Просмотр тарифов и текущей подписки<br>2. Пользователь выбирает действие с подпиской (точка расширения «Выбор действия»).<br>3. S2 [Выбран «Премиум», подписки нет] // Оформление премиум-подписки<br>4. S3 [Нажата «Отменить подписку», подписка активна] // Отмена подписки<br>5. Выполнение прецедента завершается. |
| Альтернативные потоки | Альтернативных потоков нет. |
| Потоки ошибок | E1. [Оплата отклонена]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система сообщает об отказе; тариф не меняется.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Переход к пункту 1 основного потока.<br>E2. [Уведомление платёжной системы не получено за 15 минут]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает статус «Ожидает подтверждения» и повторно запрашивает статус платежа. |
| Подпотоки | S1. «Просмотр тарифов и текущей подписки»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система показывает сравнение тарифов, текущий тариф, остаток суточной квоты и дату окончания подписки.<br>S2. «Оформление премиум-подписки»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. S4 // Оплата подписки (E1, E2)<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система активирует подписку.<br>&nbsp;&nbsp;&nbsp;&nbsp;3. S5 // Пересчёт срока хранения материалов<br>S3. «Отмена подписки»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система отключает продление; подписка действует до конца оплаченного периода.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. S5 // Пересчёт срока хранения материалов<br>S4. «Оплата подписки»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система создаёт платёж и передаёт запрос платёжной системе (сценарий СЦ4).<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Система получает результат платежа.<br>S5. «Пересчёт срока хранения материалов»<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система пересчитывает срок хранения материалов пользователя по новому тарифу: 90 дней — премиум, 7 дней — бесплатный (от даты окончания подписки). |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Иногда |
