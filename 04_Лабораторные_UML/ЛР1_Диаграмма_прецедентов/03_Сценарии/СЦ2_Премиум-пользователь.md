# СЦ2. Сценарий использования системы Премиум-пользователем

| Поле | Содержание |
|---|---|
| Название | Сценарий использования системы премиум-пользователем |
| Действующие лица | Премиум-пользователь |
| Краткое описание | Премиум-пользователь наследует сценарий Пользователя (генерализация) и дополнительно пользуется возможностями премиум-тарифа: подсказками к промпту, картинкой-референсом, разрешением 2048²/4096², увеличенным числом шагов и вариантов генерации, расширенными форматами экспорта, просмотром на своей 3D-модели. |
| Предусловия | Пользователь оформил премиум-подписку; подписка активна. |
| Постусловия | Премиум-пользователь завершил работу с системой; созданные материалы хранятся 90 дней. |
| Основной поток | 1. Выполняются пункты 1–4 сценария СЦ1.<br>2. S1. [Выбрана Генерация материала]<br>3. S2. [Выбран Просмотр материала в 3D]<br>4. S3. [Выбран Экспорт материала]<br>5. Пункты 5, 8–11 сценария СЦ1 выполняются без изменений. |
| Альтернативные потоки | A1. [Срок подписки истёк во время сеанса]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Система переводит пользователя на бесплатный тариф и сообщает об этом.<br>&nbsp;&nbsp;&nbsp;&nbsp;2. Дальнейшая работа выполняется по сценарию СЦ1. |
| Потоки ошибок | Потоки ошибок совпадают со сценарием СЦ1. |
| Подпотоки | S1. [Выбрана Генерация материала]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Выполняется поток прецедента «Генерация материала» (UC2); выполняются условия расширений «Получение подсказок к промпту» и «Учёт картинки-референса»; доступны 30–40 шагов, до 4 вариантов, разрешение 2048² и 4096²; задача ставится в очередь с высоким приоритетом.<br>S2. [Выбран Просмотр материала в 3D]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Выполняется поток прецедента UC3; доступно расширение «Просмотр на своей 3D-модели».<br>S3. [Выбран Экспорт материала]<br>&nbsp;&nbsp;&nbsp;&nbsp;1. Выполняется поток прецедента UC4; доступно расширение «Экспорт в расширенных форматах». |
| Приоритет (Критично | Важно | Желательно) | Важно |
| Частота использования (Всегда | Часто | Иногда | Редко | Один раз) | Часто |
