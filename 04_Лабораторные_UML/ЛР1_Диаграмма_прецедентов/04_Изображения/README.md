# Изображения диаграмм ЛР1

`PNG/D1…D10` — рисунки для отчёта (ширина 2048 px), `SVG/` — те же диаграммы в векторе. Отрисованы из файла модели `01_Модель/ЛР1_Прецеденты.mdj` скриптом
`_инструменты/mdj_render.py` по правилам отрисовки StarUML 6 (Arial 13 px, отсек точек расширения под
эллипсом, подписи «include» по формуле StarUML). Раскладка та же, что откроется в StarUML.

При желании заменить экспортом из самого StarUML: File → Export Diagram As → PNG, те же имена файлов.
Порядок в отчёте: D1 (основная), D3 (генерация), D2, D4, D5, D6, D7, D8 (администрирование), D9 (анализ показателей), D10 (тарифы и персонал).
