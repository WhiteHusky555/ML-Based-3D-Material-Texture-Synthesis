# Отчёт ЛР1

`Отчёт_ЛР1_Диаграмма_прецедентов.docx` — титул по Приложению А [5], тема, задание, 10 рисунков диаграмм (альбомные страницы), документирование диаграмм, 7 сценариев акторов и работников, 9 описаний потоков; 56 страниц.

Сборка: `python -I собрать_отчёт_ЛР1.py` (тексты берутся из `01_Модель/ЛР1_Прецеденты.mdj` и `03_Сценарии/потоки_ЛР1.py`, рисунки — из `04_Изображения`). `_содержание_отчёта.json` — промежуточный файл сборки.
