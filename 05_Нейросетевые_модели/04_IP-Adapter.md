# IP-Adapter — картинка-референс (премиум)

## Что это
Небольшой адаптер, который позволяет подавать в диффузионную модель **картинку как «промпт»**: модель перенимает внешний вид образца (цвета, фактуру, материал). Источник: Ye и соавт. «IP-Adapter: Text Compatible Image Prompt Adapter for Text-to-Image Diffusion Models» (Tencent AI Lab, 2023).

## Как устроено
- Картинка кодируется **кодировщиком изображений CLIP** (для SD 1.5 — OpenCLIP ViT-H/14).
- Эмбеддинги картинки подаются в U-Net через **отдельный (развязанный) cross-attention**, параллельно тексту → текст и картинка работают вместе, а не вытесняют друг друга.
- Обучаемая часть очень маленькая: ~22 млн параметров; основная модель заморожена.
- Варианты для SD 1.5: `ip-adapter_sd15` (общий стиль), `ip-adapter-plus_sd15` (точнее передаёт детали).

## Роль в нашей системе
| Что задаёт | Чем |
|---|---|
| **Форму** (где камни, трещины) | процедурный шум → ControlNet |
| **Внешний вид** (цвет, фактура, «как на фото») | картинка-референс → IP-Adapter |
| **Смысл** (что за материал, состояние) | текст → CLIP |
| **Стиль «плоская текстура»** | LoRA |

Пример: пользователь загружает фото старого кирпича из своей игры и выбирает шум-ячейки → получает бесшовный материал своей формы, но в стиле фото.

## Использование
- diffusers: `pipe.load_ip_adapter("h94/IP-Adapter", subfolder="models", weight_name="ip-adapter_sd15.bin")`, затем `pipe.set_ip_adapter_scale(0.5)`.
- **Сила референса** (`ip_adapter_scale`, 0–1) — ползунок в интерфейсе, как «image strength» у Polycam.
- Работает вместе с ControlNet и LoRA.
- Память: адаптер + кодировщик изображений ~1,3 ГБ fp16.

## Обучение
**Нет.** Готовые веса (репозиторий `h94/IP-Adapter`). Лицензия — Apache 2.0 по карточке репозитория (проверить перед ВКР; кодировщик OpenCLIP — MIT).

## Ограничения
- Референс передаёт и нежелательное: перспективу и тени с фото. Частично гасится LoRA и negative prompt; для лучшего результата советовать пользователю фото «в лоб».
- Слишком большой `scale` подавляет текст и форму — по умолчанию 0,4–0,6.
