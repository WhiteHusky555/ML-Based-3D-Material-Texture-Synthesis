# Нейросетевые модели системы

Справочник по всем моделям, которые упоминались в проекте: какие используются, как устроены, что обучается, какие лицензии.
Дата: 14.10.2026. Цифры по размерам и памяти — ориентиры; перед текстом ВКР сверить с карточками моделей на Hugging Face.

## Главное правило
**Обучается только одна модель — LoRA для SD 1.5, в курсовой** (автор не потянет обучение нескольких моделей для ВКР). Все остальные модели используются с готовыми (предобученными) весами.

## Модели в конвейере

```
                текст (англ.) ──► CLIP (текстовый кодировщик) ─┐
карта шума (форма) ──► ControlNet ───────────────────────────┤
картинка-референс (премиум) ──► IP-Adapter ──────────────────┤
                                                             ▼
                 случайный шум ──► U-Net SD 1.5 + LoRA ──(20–40 шагов)──► латент 64×64
                                                             ▼
                                                    VAE-декодер → albedo 512²
                                                             ▼
                                              Real-ESRGAN → 1024² / 2048² / 4096²
                                                             ▼
                                         PBR-сервис (формулы, без нейросети)

описание пользователя ──► LLM (подсказки к промпту, премиум) ──► 1–3 подсказки
```

| № | Модель | Роль | Обучается? | Лицензия | Файл |
|---|---|---|---|---|---|
| 1 | **Stable Diffusion 1.5** (U-Net, VAE, CLIP) | основная модель генерации текстуры | нет | CreativeML OpenRAIL-M | [01](01_Stable_Diffusion_1.5.md) |
| 2 | **LoRA** | дообучение SD 1.5 на текстурах: плоские, без перспективы и теней | **да, в курсовой** | своя (данные ambientCG — CC0) | [02](02_LoRA.md) |
| 3 | **ControlNet** | форма материала из карты процедурного шума | нет | как у SD 1.5 (проверить карточку) | [03](03_ControlNet.md) |
| 4 | **IP-Adapter** | учёт картинки-референса (премиум) | нет | Apache 2.0 (проверить) | [04](04_IP-Adapter.md) |
| 5 | **Real-ESRGAN** | увеличение разрешения ×2 / ×4 | нет | BSD-3-Clause | [05](05_Real-ESRGAN.md) |
| 6 | **LLM** (Qwen, T-Lite, GigaChat и др.) | подсказки к промпту (премиум) | нет | зависит от модели | [06](06_Языковые_модели_для_подсказок.md) |
| — | CLIP (как метрика) | оценка соответствия текстуры описанию (CLIP score) в экспериментах | нет | MIT (OpenAI CLIP) | [01](01_Stable_Diffusion_1.5.md) |

Кандидаты и перспективы (не используются в ВКР): SDXL, SD 3.5, FLUX.1 / FLUX.2, Qwen-Image, Z-Image, HiDream, закрытые сервисы (Nano Banana, GPT Image, Firefly, Midjourney), российские Kandinsky и Шедеврум — [07_Кандидаты_и_перспективы.md](07_Кандидаты_и_перспективы.md).

## Бюджет видеопамяти (fp16, ориентир)
| Компонент | Память |
|---|---|
| U-Net SD 1.5 | ~1,7 ГБ |
| VAE | ~0,2 ГБ |
| CLIP текстовый кодировщик | ~0,25 ГБ |
| ControlNet (один) | ~0,7 ГБ |
| LoRA | десятки МБ (вливается в веса U-Net) |
| IP-Adapter + кодировщик изображений (CLIP ViT-H) | ~1,3 ГБ |
| Real-ESRGAN x4plus | ~0,07 ГБ веса + активации по тайлам |
| Активации при 512², batch 1–4 | ~1–4 ГБ |
| **Итого GPU-воркер** | **~5–8 ГБ** → помещается даже в 8 ГБ; на L4 24 ГБ остаётся место под LLM 3–8B |
