# LoRA — единственная дообучаемая модель (курсовая)

## Что такое LoRA простыми словами
**LoRA (Low-Rank Adaptation, «низкоранговая адаптация»)** — способ дообучить большую готовую модель, не трогая её основные веса. К некоторым слоям модели добавляются маленькие «насадки», и учатся **только они**.

Аналогия: у нас есть художник (SD 1.5), который умеет рисовать что угодно, но по привычке рисует фотографии с перспективой и тенями. Переучивать его с нуля дорого. LoRA — это как короткий курс «рисуем плоские текстуры сверху»: художник остаётся тем же, а к его навыкам добавляется небольшая поправка.

## Как устроено математически
Есть слой с матрицей весов W (размер d × k). Полное дообучение меняло бы все d·k чисел. LoRA вместо этого учит поправку как произведение двух узких матриц:

  W' = W + (α / r) · B · A,  где B — d × r, A — r × k, ранг r ≪ min(d, k).

- **W заморожена**, учатся только A и B.
- **Ранг r** (обычно 4–64) задаёт «ёмкость» поправки.
- **α** — масштаб; при генерации силу LoRA можно менять (например, 0,6–1,0).
- Пример: слой 768 × 768 — это 589 824 веса. LoRA ранга 16 учит 768·16 + 16·768 = 24 576 весов — **в 24 раза меньше**.

Источник: Hu и соавт. «LoRA: Low-Rank Adaptation of Large Language Models» (Microsoft, 2021). Для диффузионных моделей метод перенесён сообществом в 2022–2023 гг. и сейчас поддерживается в diffusers.

## Куда в SD 1.5 ставится LoRA
Обычно в слои внимания U-Net (проекции `to_q`, `to_k`, `to_v`, `to_out`), по желанию — в текстовый кодировщик. Остальные веса SD 1.5 не меняются.

## Зачем LoRA в нашей системе
SD 1.5 «из коробки» рисует по запросу «cobblestone» фотографию мостовой: перспектива, тени, горизонт. Для материала нужна **плоская текстура сверху, с ровным освещением, без объектов**. LoRA учит модель именно такому стилю.

## Как будет обучаться (курсовая, осень 2026)
| Параметр | Значение |
|---|---|
| Данные | **300–500 текстур ambientCG** (лицензия **CC0** — общественное достояние, можно использовать коммерчески) |
| Подготовка | случайные кропы 512² из текстур 1K–2K; т. к. текстуры бесшовные, допустимы **кропы с заворачиванием** (сдвиг `roll`) — больше вариантов из той же картинки |
| Подписи | теги ambientCG / автоматические подписи + **триггер-слово** (редкий токен, например `sksTexture`) |
| Ранг | 8–32 (подбирается в курсовой) |
| Обучение | ~1500–5000 шагов, lr ≈ 1e-4, fp16, gradient checkpointing; укладывается в одну видеокарту 8–16 ГБ, порядка нескольких часов |
| Инструменты | пример `train_text_to_image_lora.py` из diffusers или kohya-ss sd-scripts |
| Идея для курсовой | обучать **с циклическим padding**, как при генерации, — тогда LoRA сразу учится на «склеенных» краях |
| Результат | файл `lora.safetensors` (единицы–десятки МБ) + `config.yaml` с настройками |

## Как используется в ВКР
- `pipe.load_lora_weights("lora.safetensors")` → `pipe.fuse_lora()` — поправка вливается в веса U-Net, генерация не замедляется.
- Триггер-слово добавляет шаблон промпта автоматически.
- Один и тот же файл LoRA — для обоих тарифов.

## Риски и как проверяются (в курсовой)
| Риск | Проверка |
|---|---|
| Переобучение (модель рисует только похожие на датасет текстуры) | разнообразие результатов, KID |
| **Копирование обучающих текстур** | поиск ближайших соседей в датасете по CLIP-эмбеддингам |
| LoRA «ломает» управление ControlNet | метрика следования структуре шума |
| Швы | ошибка на шве (разница пикселей по краям плитки) |

## Почему LoRA, а не полное дообучение
| | Полное дообучение SD 1.5 | LoRA |
|---|---|---|
| Что учится | ~860 млн параметров U-Net | единицы млн |
| Память и время | много GPU, дни | одна видеокарта, часы |
| Размер результата | ~2–4 ГБ | десятки МБ |
| Риск «забыть» общие знания | высокий | низкий — основные веса заморожены |
| Подходит под ограничение «не обучать много моделей» | нет | **да** |
