# Что делаем с моделью: база, датасет, дистилляция (исследование 11.11.2026)

Вопрос: какие открытые модели можно использовать для дистилляции и обучения, какой датасет, какая нейросеть в основе; что с моделями Qwen и MiniMax.
Лицензии, даты и размеры проверены по карточкам и файлам лицензий на Hugging Face 11.11.2026; оценки и выводы — мои.

## 1. Коротко: что мы делаем
Идея «генерируем процедурный шум и заставляем открытую нейросеть рисовать по нему текстуру» верна — это и есть план проекта. Уточнения:

| Как было в вопросе | Как на самом деле |
|---|---|
| нейросеть генерирует текстуру по шуму | SD 1.5 сама шум как форму не понимает. Шум подаётся через **ControlNet** — готовую сеть-адаптер, которая передаёт форму картинки-условия в генерацию ([03_ControlNet.md](03_ControlNet.md)) |
| может, какой-то датасет | датасет нужен **только для дообучения LoRA** (300–500 текстур), а не для обучения модели с нуля |
| дистилляция | в классическом смысле (учитель обучает свою маленькую модель-ученика) — **не делаем**: это ещё одна обучаемая модель, а по решению от 14.10.2026 обучается только LoRA. Допустимы два вида — см. раздел 5 |
| какая нейросеть в основе | **SD 1.5** (открытые веса) + ControlNet + своя LoRA. Основное ограничение — «обучаем одну модель», а не «обязательно SD 1.5»: если сменить базу, LoRA обучается для новой базы вместо SD 1.5 (раздел 6) |

Конвейер не меняется: шум (форма) → ControlNet → SD 1.5 + LoRA (фактура, бесшовно) → Real-ESRGAN → PBR-карты формулами.

## 2. Qwen и MiniMax
### Qwen-Image (Alibaba)
| Версия | Выход | Размер | Лицензия | Для нас |
|---|---|---|---|---|
| Qwen-Image, -Edit, -Layered, **-2512** | авг.–дек. 2025 | 20,4 млрд | **Apache 2.0** — коммерция разрешена | по лицензии можно, но: трансформер (DiT) — наш способ бесшовности не работает; только веса в bf16 — около 41 ГБ (20,4 млрд × 2 байта, мой расчёт), на L4 24 ГБ без квантизации не помещается |
| Qwen-Image 2.0 и 3.0 | 2026 | не опубликован | только API Alibaba Cloud | весов нет |
| **Qwen-Image 2.1** | 20.09.2026 | 7,1 млрд | **Qwen Research License**: только некоммерческое использование | нельзя в платном сервисе |
| Qwen-Image 2.1 Turbo | 09.10.2026 | 7 млрд, 8 шагов | то же | нельзя |

Вывод: Qwen-Image-2512 — сильная открытая модель «для фото», но **не база** для нас: большая, на трансформере, без зрелой бесшовности. Пригодна как «учитель» для синтетических данных (раздел 5б): Apache 2.0 это разрешает.

Поправка к нашим файлам: в `07_Кандидаты_и_перспективы.md` и `02_Архитектура_системы/15` у Qwen-Image-2512 было записано «7 млрд». По карточке и обзорам — 20,4 млрд. Исправлено.

### MiniMax
- `image-01` — модель изображений MiniMax, доступная **только через API**.
- **MiniMax-H3-Image** — открытые веса выложены 3 ноября 2026: генерация и редактирование, около 16 Мп сразу, 6 шагов. Но для нас она не подходит:
  - размер: трансформер 33,1 млрд (66,3 ГБ в BF16) плюс текстовый кодировщик 66,7 ГБ — нужны несколько серверных GPU;
  - лицензия MiniMax-H3-Image Community License **не действует в ЕС, Великобритании, США и Республике Корея**;
  - сервис для третьих лиц или выручка выше 1 млн долларов в год — только с отдельного письменного разрешения MiniMax;
  - результаты модели **запрещено использовать для улучшения других моделей**, то есть учителем для нашей LoRA она быть не может.
- MiniMax-H3 (основная модель семейства) — генерация видео со звуком, к текстурам не относится.

## 3. Готовые открытые модели именно для PBR-материалов
| Модель | Что умеет | Лицензия | Оценка для нас |
|---|---|---|---|
| **StableMaterials** (Vecchio, 2024) | по тексту или картинке сразу набор карт 512²: basecolor, normal, height, roughness, metallic; режим `tileable=True`; есть версия LCM на несколько шагов | OpenRAIL (коммерция с ограничениями по назначению; текст проверить) | самая близкая готовая модель. Её авторы сделали именно «дистилляцию»: знания большой SDXL перенесены в модель материалов полу-контролируемым обучением, плюс 4000 пар «текстура — текст», сгенерированных SDXL. Минусы: формой из нашего шума не управляется (нет ControlNet), с LoRA и ControlNet от SD 1.5 несовместима, только 512² (refiner не выложен) |
| **MatFuse** (CVPR 2024) | карты diffuse, normal, roughness, specular; условия — текст, картинка, **эскиз контуров**, палитра | MIT (код и веса) | эскиз позволяет задать форму, например контурами Вороного. Модель 2023 года, нужно 12 ГБ видеопамяти, карты height нет |
| Chord (Ubisoft La Forge, 2025) | восстанавливает PBR-карты из сгенерированной текстуры | Ubisoft ML License: только исследования, копилефт; доступ по запросу | в платный сервис нельзя |
| Material Anything (2024) | материалы для 3D-объектов | — | другая задача (текстурирование модели) |

Вывод: готовая модель для PBR существует (StableMaterials), но у неё нет главного — управления формой через процедурный шум, а также пути к 1K–4K и совместимости с нашей экосистемой. Поэтому в базу её не берём. Её стоит использовать как **точку сравнения** в экспериментах: CLIP score, ошибка на шве, время. Это предложение, решение за вами.

## 4. Датасет
| Датасет | Что внутри | Лицензия | Для чего |
|---|---|---|---|
| **ambientCG** | тысячи бесшовных PBR-материалов | CC0 | уже выбран для LoRA |
| **MatSynth** (Vecchio, Deschaintre, CVPR 2024) | **4069 бесшовных материалов 4K** с полным набором карт (basecolor, diffuse, normal, height, roughness, metallic, specular); метаданные: категория, теги, источник, лицензия; разбиение train 3980 / test 89 | CC0 (ambientCG, Poly Haven, CGBookCase, ShareTextures, TextureCan) и небольшая часть CC-BY (Julio Sillet) | **рекомендую** как источник для LoRA вместо ручного скачивания: фильтр `license == CC0`, по 25–40 материалов на категорию. Тестовая часть — эталон для замеров, в том числе эталонные карты для проверки наших формул PBR (сейчас у качества карт нет числовой метрики) |

Объём MatSynth (4K-карты) я не проверял: он большой, качать лучше выборочно, через streaming и фильтр.

## 5. Дистилляция: что можно, а что нет
### 5а. Ускорение генерации: готовые дистиллированные адаптеры (обучать не нужно)
Такой адаптер — это LoRA, которую уже обучили авторы. Она позволяет SD 1.5 рисовать за 2–8 шагов вместо 20–40. Можно использовать для быстрого превью.

| Адаптер для SD 1.5 | Лицензия по карточке | Можно в платном сервисе |
|---|---|---|
| LCM-LoRA (`latent-consistency/lcm-lora-sdv1-5`) | OpenRAIL++ | да |
| TCD-LoRA (`h1t/TCD-SD15-LoRA`) | MIT | да |
| Hyper-SD15 (ByteDance) | в карточке не указана | только после выяснения лицензии; совместимость с ControlNet показана в README |
| DMD2 | CC BY-NC 4.0 | **нет** (некоммерческая) |
| PCM | в карточке не указана | только после выяснения лицензии |

Риск: у авторов StableMaterials обычная бесшовность хуже работает при генерации за несколько шагов, поэтому они сделали «сдвиг признаков» (features rolling). Значит, бесшовность при LCM или TCD нужно отдельно проверить в курсовой.

### 5б. Синтетические данные от большой модели («учитель → наша LoRA»)
Большая открытая модель генерирует плоские текстуры по списку промптов, и они добавляются к датасету LoRA (так StableMaterials сделали с SDXL). Отдельная модель при этом не обучается. Лицензия учителя должна это разрешать:

| Учитель | Можно ли использовать результаты для обучения своей модели |
|---|---|
| Qwen-Image-2512, Z-Image-Turbo, FLUX.2 [klein] 4B, FLUX.1 [schnell] | Apache 2.0 — запрета нет |
| SDXL | OpenRAIL++ — разрешено с ограничениями по назначению |
| MiniMax-H3-Image | **запрещено** лицензией |
| Qwen-Image 2.1, FLUX.2 [dev] / [klein] 9B | некоммерческие лицензии — не подходят для платного сервиса |

Моя оценка: реальные CC0-текстуры (MatSynth, ambientCG) лучше синтетики для обучения «плоского» стиля. Синтетику стоит добавлять только если в каких-то категориях не хватает материалов.

### 5в. Классическая дистилляция «учитель → своя маленькая модель»
Не делаем: это вторая обучаемая модель, нужны дни GPU и большой датасет. Это уровень исследовательской статьи (как StableMaterials), а не ВКР.

## 6. Какая нейросеть в основе
**Остаётся SD 1.5 + ControlNet + LoRA.** Модель старая (2022), качество ниже современных, но она одна закрывает все требования:
1. Наша бесшовность (циклический padding в свёртках U-Net) работает.
2. Есть готовые ControlNet для формы из шума (depth, softedge, canny, tile).
3. Коммерческая лицензия (CreativeML OpenRAIL-M).
4. Помещается в 8 ГБ, LoRA обучается за часы на одной видеокарте.

Веса брать из зеркала `stable-diffusion-v1-5/stable-diffusion-v1-5` (лицензия creativeml-openrail-m): исходный репозиторий runwayml удалён с Hugging Face. Карточки ControlNet по-прежнему ссылаются на него как на базу.

**Самый перспективный современный вариант — Z-Image-Turbo** (Alibaba Tongyi, ноябрь 2025):
- 6 млрд параметров, 8 шагов, Apache 2.0; по карточке помещается в 16 ГБ;
- есть ControlNet Union (`alibaba-pai/Z-Image-Turbo-Fun-Controlnet-Union`, Apache 2.0) — форма из шума возможна.

Запасной вариант — FLUX.2 [klein] 4B (Apache 2.0, около 13 ГБ). Шаблон ControlNet для неё у DiffSynth-Studio выложен, но, судя по нулю скачиваний, ещё не обжит.

Что мешает взять Z-Image-Turbo сейчас:
1. Это трансформер (DiT): циклический padding работает только в VAE, а для самой сети нужен другой приём. Проверенного готового метода бесшовности для DiT в найденных источниках нет. Типовой приём — сдвиг латента на случайное смещение на каждом шаге (как «features rolling» у StableMaterials), его нужно проверять экспериментом.
2. LoRA пришлось бы обучать для Z-Image, а не для SD 1.5. Видеопамять для такого обучения я не проверял.

Предложение (решение за вами): в курсовой одним небольшим опытом проверить «Z-Image-Turbo + ControlNet Union + сдвиг латента» на 20–30 текстурах. Если бесшовность получится — обсудить смену базы. Если нет — SD 1.5, как сейчас. Правило «обучаем одну модель» при этом не нарушается.

Другие открытые модели 2026 года — FLUX.2, HiDream-O1-Image и GLM-Image (MIT), ERNIE-Image, LongCat-Image, MOSS-Image (Apache 2.0) — тоже трансформеры. Лицензии для них я брал из обзоров, по карточкам не проверял. Krea 2 и SD 3.5 бесплатны только при выручке до 1 млн долларов в год; Ideogram 4 и FLUX.2 [klein] 9B — некоммерческие.

## 7. Итог: план
| Шаг | Что | Где |
|---|---|---|
| 1 | Набрать 300–500 CC0-материалов из MatSynth (фильтр по лицензии, равномерно по категориям), кропы 512² со сдвигом | курсовая |
| 2 | Выбрать ControlNet (depth / softedge / tile) для шума; простейшая точка сравнения — img2img из карты шума без ControlNet | курсовая |
| 3 | Обучить одну LoRA для SD 1.5 (с циклическим padding) | курсовая |
| 4 | Сравнить с StableMaterials (готовая модель PBR) по CLIP score, ошибке на шве и времени | курсовая или эксперименты ВКР |
| 5 | Проверить LCM-LoRA или TCD для быстрого превью: держится ли бесшовность | курсовая |
| 6 | Если есть время — опыт с Z-Image-Turbo + ControlNet Union (раздел 6); на Kaggle — только генерация, без обучения LoRA (раздел 8) | курсовая, по желанию |
| 7 | В сервисе — лучшая конфигурация как готовый компонент; карты PBR формулами, проверка их по эталонным картам тестовой части MatSynth | ВКР |

## 8. Влезает ли это в ноутбук Kaggle
Работа (курсовая) идёт в обучающем ноутбуке Kaggle. Недельную квоту часов GPU здесь не учитываю — проверено только, помещается ли всё технически.

**Что даёт ноутбук** (документация Kaggle, 11.11.2026):
- GPU на выбор: T4 ×2 (2 × 16 ГБ) или P100 (16 ГБ); 4 ядра CPU, 29 ГБ ОЗУ;
- сессия до 12 часов; «Save & Run All» выполняет весь ноутбук в фоне, тоже до 12 часов;
- сохраняются 20 ГБ в `/kaggle/working`; есть дополнительное временное место, которое после сессии не сохраняется;
- GPU и интернет (нужен для загрузки моделей с Hugging Face) доступны только аккаунту с подтверждённым телефоном.

**Брать только T4 ×2.** В текущей среде Kaggle стоит PyTorch 2.10 для CUDA 12.8, в нём нет кернелов для P100 (sm_60): операции падают с ошибкой «no kernel image is available». На T4 всё работает (Kaggle/docker-python, issue #1546). Нативного bf16 у T4 нет, поэтому обучение идёт в fp16; для LoRA SD 1.5 это стандартный режим, у kohya он стоит по умолчанию.

| Задача | Сколько нужно | Влезает в T4 ×2 |
|---|---|---|
| Обучение LoRA для SD 1.5, 512², fp16, gradient checkpointing | по руководствам — GPU на 6–8 ГБ | **да**, с запасом на одной T4; на второй можно параллельно гонять другой вариант (например, другой ранг) |
| Генерация SD 1.5 + ControlNet + LoRA, сравнение 4 вариантов ControlNet | около 5–8 ГБ ([README](README.md)) | **да** |
| LCM-LoRA или TCD для быстрого превью | десятки МБ сверху | **да** |
| StableMaterials (точка сравнения) | 0,86 млрд параметров: около 1,7 ГБ в fp16 (мой расчёт по весам) | **да** |
| MatFuse | по словам авторов, от 12 ГБ | **да**, на одной T4 впритык |
| Z-Image-Turbo, генерация | трансформер 6,15 млрд: около 12,3 ГБ в 16 битах, плюс текстовый кодировщик (размер не проверял) | **только с риском**: кодировщик на одной T4, трансформер на другой. Модель рассчитана на bf16, на T4 придётся fp16 — возможны ошибки переполнения (NaN), нужна проверка |
| LoRA для Z-Image | веса 12,3 ГБ + градиенты + активации | **практически нет**: без квантизации базы до 4–8 бит в 16 ГБ не помещается, а квантизацию я не проверял. Ещё один довод оставить SD 1.5 |
| Qwen-Image-2512, MiniMax-H3-Image | около 41 ГБ и больше 130 ГБ | **нет** |

**Датасет в Kaggle:**
- MatSynth целиком весит 433 ГБ: train — 425,6 ГБ (431 файл parquet), test — 7,4 ГБ. В 20 ГБ он не влезает, а на самом Kaggle его нет (поиск по датасетам пуст).
- Тестовая часть (7,4 ГБ) помещается целиком во временное место; это эталон для замеров.
- Для LoRA из train читать только нужные столбцы (basecolor и metadata) с фильтром по лицензии и сразу сохранять кропы 512²–1K. Формат parquet позволяет читать отдельные столбцы. На 500 материалов результат — порядка 1 ГБ; объём того, что придётся скачать, я не проверял.
- Проще другой путь: брать 1K–2K архивы ambientCG напрямую. По моей оценке, 500 материалов — несколько гигабайт.
- Датасет удобно подготовить один раз в сессии без GPU и сохранить как свой приватный датасет Kaggle, а к ноутбуку обучения подключать как вход.

**Как работать в ноутбуке:**
- отладка — в интерактивной сессии, долгое обучение — через «Save & Run All»;
- чекпоинты LoRA сохранять в `/kaggle/working` каждые N шагов: файл весит десятки мегабайт, а сессия может оборваться;
- модели — с Hugging Face при включённом интернете или как входы ноутбука.

Время обучения на T4 я в источниках не нашёл. Замерить пробным прогоном на 100 шагов и по нему выбрать число шагов.

**Вывод:** шаги 1–5 и 7 плана помещаются в один ноутбук на T4 ×2. Шаг 6 (Z-Image) — только генерация и с риском. Обучать LoRA для Z-Image на Kaggle не получится.
